# 09｜承诺书流程（T030）

> 状态：Owner 已确认 / 原型收口依据  
> 日期：2026-08-24  
> 适用：三创赛 PC 报名门户

## 1. 已确认结论

两份承诺书都保留：

1. 学生 / 参赛团队承诺书；
2. 指导老师承诺书。

不做页面内电子签名，也不要求签字文件回传系统。统一流程为：

```text
生成 / 下载
→ 打印
→ 手写签字
→ 按赛事材料要求线下使用
```

## 2. 原型只表达必要状态

每份承诺书只需要两个用户可感知状态：

- 待生成；
- 可下载。

签字属于线下材料环节，不在核心学院系统继续追踪“已签字 / 已上传 / 已审核”等状态。

## 3. 两份文件的关系

### 学生 / 团队承诺书

沿用当前项目标题、项目摘要、创新点、创意点、创业点等报名内容生成。

### 指导老师承诺书

保留入口文案：

> 下载指导老师承诺书模板

老师承诺书复用当前团队 / 项目信息，不要求指导老师再录一遍项目内容。

指导老师信息可以后置补充，不阻塞前面的团队报名与学校审核。

## 4. 页面结构

学校审核通过后进入承诺书页：

```text
项目信息
↓
学生 / 团队承诺书
  下载 → 打印签字
↓
指导老师承诺书
  下载模板 → 打印签字
↓
无需回传系统
→ 完成报名
```

页面应明确告诉队长：签字件按赛事材料要求线下使用，不需要上传回核心学院。

## 5. 完成条件

核心学院系统不校验线下签字结果。

原型中两份承诺书生成后即可完成报名；打印和手写签字由线下赛事材料流程承接。

## 6. 当前不做

- 页面内电子签；
- 签字文件上传；
- 文件审核；
- 多版本文件管理；
- 自动识别签字真实性；
- OCR / 电子签章；
- 老师端单独再造一套承诺书制作流程。

T032 教师工作台也不需要因此增加承诺书文件审核入口。
