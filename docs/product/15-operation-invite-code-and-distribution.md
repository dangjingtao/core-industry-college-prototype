# T036｜运营邀请码 / 地推扫码

## 定位

邀请码与扫码不是同一功能。

### 邀请码

用于运营人员阶段性推广活动：

- 活动福利码；
- 校园推广码；
- 限时领取活动。

用户流程：

```text
活动入口
→ 输入邀请码
→ 校验
→ 领取权益
```

不建立邀请关系。

### 扫码

用于地推/分销渠道归因：

```text
地推二维码
→ 活动落地页
→ 注册/登录
→ 记录渠道来源
```

用户不需要理解分销关系。

## 原型范围

本期实现：

- 活动邀请码入口；
- 扫码入口保留；
- 领取结果展示。

不实现：

- 多级分销；
- 邀请排行榜；
- 佣金体系；
- 渠道后台。

## 入口原则

邀请码不放深层设置。

优先：

- 首页活动入口；
- 福利活动卡片。

用户不会主动寻找邀请码，而是被活动触达。
