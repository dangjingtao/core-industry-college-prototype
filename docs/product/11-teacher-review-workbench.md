# 11｜T032 教师审核工作台

> 状态：原型主流程已收口  
> 日期：2026-08-24  
> 范围：学校教师 PC 审核工作台，不是综合运营后台。

## 已确认方向

教师端只承担学校审核职责：

```text
系统分配教师账号
→ 账号 + 密码登录
→ 自动进入授权学校
→ 查看本校报名团队
→ 查看团队 / 项目基础信息
→ 通过或驳回
→ 查看审核记录
```

## 原型边界

- 教师无需自主注册；
- 不再使用“选择姓名”式登录；
- 默认列表只显示当前授权学校的团队；
- 不提供跨校统计、跨校筛选或平台运营数据；
- 教师只处理报名审核，不复制平台运营控制面；
- 承诺书为线下下载打印签字材料，不回传系统，因此教师工作台不增加承诺书文件审核；
- 学生 App 不提供教师审核入口。

## 当前审核动作

原型保留最少两种：

- 审核通过；
- 驳回并填写原因。

“退回补充”“多级审核”“减员由谁审核”等真实规则尚未确认，不在本卡提前设计。

## 当前不做

- 教师账号创建后台；
- 一个教师多学校 / 多范围权限模型；
- 跨校数据视图；
- 综合教务管理；
- 承诺书审核；
- 平台运营能力；
- 完整审计 / 权限系统。

这些待真实业务规则明确后再决定是否进入后续实现。
