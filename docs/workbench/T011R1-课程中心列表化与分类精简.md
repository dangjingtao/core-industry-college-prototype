# T011R1｜课程中心列表化与分类标签精简

**类型：施工卡（T011 方向修订）**  
**状态：部分完成**  
**优先级：P1**

## 当前原型完成度

- [x] `/courses/center` 已改为列表样式（左侧封面小图 + 右侧标题/简介/课时/价值标签/状态），不再是网格商城样式。
- [x] 已使用与「机会」页一致的 `MobileFilter` 弹窗筛选器，支持「专业方向」和「价值维度」筛选。
- [ ] 学院首页 `/courses` 仍保留「课程中心」标题 + 「在学/已学完」Tab + 宫格入口，未完全简化为单一「全部课程」入口。
- [ ] 课程卡片上仍显示 `CategoryTag` 分类标签，未去除不必要的标签分类。

## 背景

T011 已完成课程中心 `/courses/center`，采用顶部搜索 + 左侧分类标签栏 + 顶部 value/sort tab + 课程网格卡片展示，视觉偏「商城样式」。

昨天下班前内部会议要求：

1. 课程中心简化为一个入口，引导至「全部课程」页面；
2. 课程列表采用列表形式而非商城样式；
3. 去除不必要的标签分类。

课程详情页、学习-考试-证书闭环不受影响。

## 目标

按会议决策简化课程中心入口与列表呈现，由商城式网格改为列表式，并精简分类标签。

## 最低交付

- [ ] 学院首页 `/courses` 仅保留一个清晰的「全部课程」入口（去除多余的分类 tab 或宫格入口）。
- [ ] `/courses/center` 课程列表由网格卡片改为列表项：
  - 左侧课程封面小图；
  - 右侧课程标题、一句话简介、课时/节数、价值标签、学习状态；
  - 点击整行进入课程详情。
- [ ] 分类与筛选精简：
  - 保留最必要的筛选维度（如专业方向或免费/需学力值二选一，不再同时展示多个标签栏）；
  - 去除当前左侧分类标签栏与顶部 sort tab 的冗余组合；
  - 若保留筛选，统一使用与「机会」页一致的 `MobileFilter` 弹窗筛选器。
- [ ] 搜索功能保留，样式与列表更协调。
- [ ] 课程详情页、学习页、考试页、证书领取逻辑保持 T011 已交付闭环不变。
- [ ] 通过 mobile `typecheck` / `build`。

## 禁止

- 不破坏课程报名/学习/考试/证书的事实边界。
- 不自行决定学力值是否可消费；兑换逻辑继续依赖 F04 Decision A 占位。
- 不为了精简而删除必要的课程信息（标题、简介、课时、价值、状态）。

## 验收动线

```text
学院首页 → 全部课程 → /courses/center
  → 列表展示课程
  → 搜索 / 筛选弹窗
  → 点击课程 → 课程详情
  → 简介/目录/成就 Tab、报名/学习/考试/证书流程保持不变
```
