## 二、S6｜职业规划｜当前 Mockplus 实例：公司推荐｜131–134

### 范围纠正

六阶段产品语义把 S6 称为“职业规划”，但当前 Mockplus 真正画出的完整任务链是：

```text
职业规划
→ 公司推荐动态答题
→ 公司推荐生成确认
→ 公司推荐任务进度
→ 公司推荐成果详情
```

因此本卡 **P0 必须实现公司推荐实例**，不得自行扩展成完整职业规划报告、能力雷达或黑盒人才评分。

### 动态答题｜Mockplus 131

- [ ] 标题为“公司推荐”。
- [ ] 动态问答逐题呈现。
- [ ] 行业偏好多选，例如互联网 / 科技、金融科技、软件开发 SaaS 等。
- [ ] 城市偏好多选。
- [ ] 保留 AI 动态准备下一题、完善度、补充说明等 Pattern。
- [ ] 可结合当前用户已有参赛档案作为输入，但可信事实只读。

### 生成确认｜Mockplus 132

- [ ] 展示问答摘要、AI 提取核心信息、主观补充、完善度。
- [ ] 展示预计算力 / 冻结提示。
- [ ] 支持确认生成 / 返回修改。
- [ ] **明确显示“生成结果仅自己可见”。**
- [ ] 事实与 AI 建议必须区分标注。

### 任务进度｜Mockplus 133

- [ ] 生成“公司推荐小报告”。
- [ ] 复用共用进度 Pattern。
- [ ] 可离开页面，完成后站内消息通知。

### 成果详情｜Mockplus 134

- [ ] “公司推荐小报告”作为成果主体。
- [ ] 展示推荐企业卡片 / 企业信息。
- [ ] 可从推荐结果进入现有企业详情能力时，复用已有 Company stable id / route，不新建第二套企业对象。
- [ ] 推荐只能作为建议，不得写入 StudentProfile、比赛成绩、证书或其它可信事实。
- [ ] 不生成不可解释的人才总分。

- [ ] 所有工坊任务继续依附具体 `competitionId` / workspace。

- [ ] AI 结果与系统事实明确分层。

```text

+ legacy-page-map 目标 route

```

不得把明显复制粘贴错误当成产品要求。
