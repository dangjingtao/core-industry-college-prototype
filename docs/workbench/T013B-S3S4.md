## 四、成果确认闭环

T013B 直接复用 T013A 已完成的 result-scoped pending 状态，不再只改按钮文案：

```text
队员编辑成果
→ 保存编辑并提交确认
→ resultConfirmationStatus[resultId] = pending
→ 离开成果页
→ 再次进入同一 result
→ 队长看到「队员已提交确认」
→ 队长采纳并用于比赛
→ acceptedResultIds 加入 resultId
→ 对应 pending 被清除
```

角色原型边界：

- 队员视角：可编辑、分享、提交队长确认；不可显示“队长采纳并用于比赛”。
- 队长视角：可看到 pending，并执行采纳。
- 已采纳成果不再显示待提交 / 待采纳动作。
