# PC07｜系统设置：短信能力 + 内容模板

> 类型：施工卡 / 平台基建  
> 状态：已施工（待复审）  
> 优先级：P1  
> 分支：`dev`  
> 前置：PC01 控制面底座  
> 决策来源：2026-08-19 PC 原型接入需求讨论

---

## 1. 背景

旧后台存在“系统设置”能力，但信息架构混杂了上传配置、短信配置、隐私协议、队列、发送记录等不同性质内容。

本卡不照搬旧后台菜单，而是只吸收当前核心产业学院 PC 明确需要的平台基础能力：

```text
系统设置
├─ 短信管理
│  ├─ 短信配置
│  └─ 短信发送记录
└─ 内容模板
   └─ 模板管理
```

目标是补齐平台基础设施，不新增与现有业务冲突的消息中心、审批流或队列系统。

---

## 2. 路由与导航

新增一级后台导航：

```text
系统设置
```

推荐路由：

```text
/admin/settings
/admin/settings/sms
/admin/settings/content-templates
```

允许用同一路由下 tabs / secondary nav 实现，但最终必须有明确可达入口。

---

## 3. 短信配置

短信配置页至少表达：

- 启用 / 停用；
- 测试模式；
- 短信服务商；
- Access Key；
- Secret Key；
- 默认短信签名；
- 业务模板映射；
- 最近修改时间；
- “发送测试短信”原型动作。

### 3.1 密钥边界

- Access Key / Secret Key 默认掩码显示；
- 不在页面上长期裸显真实 Secret；
- 原型数据只能使用明显的 mock / masked value；
- 不把任何真实第三方密钥提交进仓库。

### 3.2 模板映射

不沿用旧后台“一套配置只有一个模板 ID”的做法。

短信模板应按业务类型映射，例如：

```text
验证码
报名结果通知
审核结果通知
系统通知
```

每项可表达：模板名称、第三方模板 ID、状态。

短信模板与 PC07 的“内容模板”不是同一对象：短信模板受第三方服务商审核 / 模板 ID 约束；内容模板属于平台自有富文本内容。

---

## 4. 短信发送记录

“短信发送状态”统一落为：

```text
短信发送记录
```

列表至少包含：

- 脱敏手机号；
- 业务类型；
- 服务商；
- 发送时间；
- 状态：发送中 / 成功 / 失败；
- 失败原因（失败时）；
- 模板或模板 ID；
- 可追踪标识（原型可使用稳定 mock id）。

至少支持：

- 时间筛选；
- 手机号关键字筛选；
- 状态筛选；
- 业务类型筛选。

首版不建设短信队列调度器，也不把“队列管理”从旧系统直接搬进来。

---

## 5. 内容模板

后台导航名称使用：

```text
内容模板
```

而不是“常见富文本模板”。

首版至少提供以下示例类型：

- 用户协议；
- 隐私政策；
- 用户消息模板；
- 系统通知模板；
- 报名 / 审核结果通知内容。

模板列表至少包含：

- 模板名称；
- 模板类型；
- 状态；
- 更新时间；
- 编辑入口。

编辑态提供中保真富文本编辑体验，允许保存 / 发布原型状态。

本卡不自行扩展复杂版本管理、多人协作、审批发布或内容 A/B Test。

---

## 6. 数据与真相源边界

1. 系统设置属于平台配置层，不成为学生 / 赛事 / Organization 的新业务真相源；
2. 内容模板只负责可复用内容，不新造通知投递记录；
3. 短信发送记录是投递证据，不替代 Audit Log；
4. 若未来接真实短信服务商，替换 provider adapter / API 层即可，页面语义不需要推翻；
5. 用户协议 / 隐私政策未来若被 App / Web 消费，应保留稳定 template key，而不是只靠中文名称查找。

---

## 7. 最低交付

1. PC 后台出现“系统设置”入口；
2. 短信配置可查看 / 编辑结构化 mock 配置；
3. Secret 默认掩码，不提交真实凭据；
4. 可触发一次“发送测试短信”原型反馈；
5. 短信发送记录可按状态 / 时间 / 业务类型筛选；
6. 至少存在成功与失败两类可复现记录；
7. 内容模板列表可查看并进入编辑；
8. 至少提供用户协议、隐私政策、用户消息 / 系统通知示例；
9. 短信第三方模板与平台富文本模板保持两个概念；
10. TypeScript / Vite build 通过；
11. 补 focused browser assertion：系统设置入口、Secret 掩码、短信记录筛选、内容模板编辑入口。

---

## 8. 禁止

- 不照搬旧后台“系统设置大杂烩”；
- 不提交真实 Access Key / Secret Key；
- 不把短信模板 ID 与富文本模板混成同一对象；
- 不新增第二套 Audit Log；
- 不建设短信队列调度器；
- 不为富文本模板扩展复杂 CMS；
- 不修改 PC01–PC06 已确认业务语义。
