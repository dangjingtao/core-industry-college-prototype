# T016｜首页核心功能区重构

**类型：施工卡**  
**状态：待执行**  
**优先级：P0**

## 当前原型完成度

- [ ] 首页首屏仍为「当前赛事 / 报名中」大卡片，不是以「赛事 + 实习」为并排的两大核心入口。
- [ ] 「任务专区」模块仍存在（`HomeTaskZone`），未更名为/重构为「动态」。
- [ ] 「合作企业」仅在「探索你的下一站」底部作为 5 个次级宫格入口之一，未前置展示，也没有在首页提供筛选器。
- [ ] 赛事 / 实习相关元素已有（赛事推荐卡片、实习与项目卡片），但视觉层级和首页主次结构不符合会议要求。

## 背景

当前 `/home` 首页包含 Banner、四宫格入口（赛事、实习、课程、福利等）、推荐内容等模块，但主次不够清晰。

昨天下班前内部会议要求：

1. 首页布局以「赛事」和「实习」为核心入口，其他功能区次之；
2. 将「任务专区」调整为「动态」；
3. 「机会」板块前置展示合作企业信息，并支持通过筛选器查找。

## 目标

重构首页信息架构与视觉层级，突出赛事与实习两大核心入口，将任务改为动态聚合，并在机会板块前置企业信息。

## 最低交付

### 首页首屏

- [ ] 顶部保留个人信息/问候与通知入口。
- [ ] 首屏核心区域突出两个一级入口：
  - **赛事**：点击进入 `/competitions` 或当前进行中的赛事工作区；
  - **实习**：点击进入 `/opportunities` 或实习/机会专区。
- [ ] 两个核心入口采用大卡片或强视觉权重，区别于次级入口。

### 动态模块（原任务专区）

- [ ] 将首页「任务专区」模块更名为/重构为「动态」。
- [ ] 「动态」展示用户相关的下一步动作与平台通知：
  - 待完成的赛事任务 / 工坊任务（读取现有 domain store，不新建第二真相源）；
  - 新课程/活动推荐；
  - 通知/消息摘要；
  - 点击查看更多进入 `/tasks` 或对应业务页面。
- [ ] 保持 D03 冻结原则：只做派生聚合展示，不恢复旧日常/核心/企业任务，不定义统一奖励。

### 机会板块企业前置

- [ ] 首页「机会」板块前置展示合作企业列表（而非仅展示岗位卡片）。
- [ ] 企业展示包含：企业 Logo/名称、一句话简介、在招机会数、关注按钮。
- [ ] 支持筛选器：按行业、地区、企业类型等维度筛选（复用 `MobileFilter` 弹窗模式）。
- [ ] 点击企业进入 `/companies/:companyId`，点击在招机会进入 `/opportunities/:opportunityId`。

### 次级入口

- [ ] 课程、福利/兑换中心、可信空间、资讯、赛友内容等入口按重要程度降级排列，不抢占赛事/实习核心位置。
- [ ] 首页底部导航保持不变：首页 / 赛事 / 机会 / 我的。

## 禁止

- 不把首页做成旧 Mockplus 的 1:1 复刻。
- 不因为企业前置就把机会模块做成招聘平台。
- 不违反 D03 冻结原则，在「动态」中新建任务真相源。
- 不破坏赛事身份与长期账号的事实边界。

## 验收动线

```text
首页
  → 赛事（核心入口）→ /competitions 或当前赛事 workspace
  → 实习（核心入口）→ /opportunities 或实习专区
  → 动态（原任务专区）→ 聚合展示待办/通知/推荐 → 跳转对应业务页
  → 机会板块 → 合作企业列表 + 筛选 → 企业详情 / 岗位详情
  → 次级入口：课程 / 兑换中心 / 可信空间 / 资讯 / 赛友
```
