# T015｜登录注册流程

**类型：施工卡**  
**状态：待执行**  
**优先级：P0**

## 背景

旧原型登录/注册流程包含邮箱登录、账号密码/验证码登录、信息填写、预备页/引导页。新原型当前直接进入已登录状态，缺少登录注册流程。

> 注意：F01 已建立 StudentProfile 学生主档，本卡在此基础上补充登录注册与 onboarding 引导。

## 目标

实现普通的登录注册流程，并在注册/登录后引导学生完善必要资料。

## 最低交付

- [ ] 启动页 / 预备页：首次进入的功能介绍（可跳过）。
- [ ] 登录页：手机号/邮箱 + 密码登录、验证码登录、忘记密码入口。
- [ ] 注册页：手机号/邮箱注册、验证码、设置密码、用户协议/隐私政策勾选。
- [ ] 信息填写页：完善个人资料（昵称、学校、专业、城市、身份类型等），复用 F01 StudentProfile。
- [ ] 登录状态管理：登录后进入首页，未登录时访问需要登录的页面引导登录。
- [ ] 退出登录后回到登录页（F03 已处理退出逻辑，本卡确认登录页承接）。
- [ ] 表单校验：手机号/邮箱格式、验证码占位、密码强度提示。

## 禁止

- 不引入真实后端鉴权；登录/验证码使用 mock，状态明确。
- 不把旧 7 步问卷调查恢复（已明确取消）。
- 不新建独立 profile 与 F01 StudentProfile 脱节。
- 不伪造真实短信/邮件验证码发送。

## 验收动线

```text
启动页（可跳过）
  → 登录页
  → 注册页 → 验证码 → 设置密码
  → 信息填写（复用 StudentProfile）
  → 首页

已登录 → 我的 → 退出登录 → 登录页
```

- F03｜退出登录
