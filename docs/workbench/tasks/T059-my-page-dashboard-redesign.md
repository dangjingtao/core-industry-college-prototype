# T059｜「我的」页面 Dashboard 化重构

**类型：原型设计 / 施工卡**  
**状态：TODO**  
**优先级：P1**  
**范围：Mobile `/me` 视觉与信息架构重构**  
**前置：T014、T055–T058 已有学习排行榜能力**

## 背景

当前 `/me` 仍以「顶部资料大卡 + 服务入口纵向列表 + 关于 / 账号列表」为主，信息层级偏设置页，个人中心感不足。

本轮确认新的方向：参考成熟个人中心的**布局结构、信息节奏和分组方式**，把 `/me` 改成个人中心 Dashboard；**只借鉴布局，不复制参考图的黑金 / 橙色视觉**，颜色、圆角、文字、边框、状态和交互全部使用核心学院现有 Com Design / design token。

T014 中旧的「当前服务统一使用纵向入口列表」规则从本卡起不再作为 `/me` 主页面约束。

## 目标

把 `/me` 从「设置型列表页」重构为：

```text
个人身份区
→ 核心业务大卡（阅读中心）
→ 我的学习
→ 学习排行榜 Banner
→ 更多服务
→ 低频账号操作
```

页面应更像学生自己的长期个人中心，而不是系统设置目录。

## 施工范围

主要实现：

- `apps/mobile/src/features/ambassador/AmbassadorAwareMyPage.tsx`
- 必要时补充 `/me` 专项样式 / 小组件，但不得另起一套视觉系统。
- 新增专项回归建议：`apps/mobile/tests/t059-my-page-dashboard.spec.ts`。

原则上不重做二级业务页；本卡负责首页信息架构、入口编排和视觉重构。

## 1. 顶部个人身份区

- `/me` **移除独立 `PageHeader title="我的"`**，页面从个人资料本身开始。
- 头像、姓名 / 昵称、学校 / 专业形成一个紧凑的横向身份区，不再包成当前的大面积 Banner 资料卡。
- 已存在的角色徽章（如校园大使）跟随姓名或学校信息展示；仅显示真实已有状态，不创建新角色状态。
- 当前资料无头像字段时继续使用现有可解释的首字 / 默认头像 fallback，不伪造真人头像。
- 资料区整体或明确入口可进入 `/me/profile`；不再额外占一整行「编辑基础资料」。
- 右上角保留「扫一扫」与「设置」两个轻量图标入口：
  - 扫一扫沿用现有原型扫码能力；
  - 设置进入 `/me/settings`。
- 所有点击区满足现有 mobile touch target token。

## 2. 核心业务大卡：阅读中心

在身份区之后放置本页最强视觉卡，承接「阅读中心」入口。

### 结构

- 左侧：阅读语义图标；
- 中部：`阅读中心` + 一行辅助说明；
- 右侧：明确的「进入阅读」操作；
- 若已有真实阅读统计，可在卡片下半部展示；**没有真实数据时不得为了贴参考图硬造“连续阅读 / 已读本数 / 时长 / 书架数量”等数字。**

### 路由边界

当前 `dev` 基线未发现正式阅读中心 route。本卡施工时：

- 若阅读功能已由其他任务合入，接入其正式 route；
- 若仍未合入，只允许把此卡作为明确的「待接入阅读功能」容器，并在施工 / 验收记录中说明；
- **禁止把 `/stories`、课程或其它无关页面临时冒充阅读中心。**

### 视觉

- 不使用参考图黑色大卡、橙金按钮或硬编码相似色；
- 使用现有 `primary / primary-pressed / primary-container / surface / text-* / border-*` 等语义 token；
- 允许用品牌主色的克制渐变建立主卡层级，但不得新增脱离 token 的主题色。

## 3. 「我的学习」四宫格

阅读卡之后使用 4 列快捷入口，替代纵向入口列表的学习相关部分。

入口必须优先映射当前真实能力。建议按当前已有 route 组织：

- 我的课程 → `/courses/center`
- 学习成果 / 学习记录 → `/assets/learning`
- 我的证书 → `/assets/certificates`
- 第四项从当前真实学习 / 成果能力中选择（如赛事成绩 `/assets/results` 或长期简历 `/me/resume`）

**不得为了复刻参考图凭空增加一个没有独立业务和 route 的「我的考试」页面。**

图标统一使用 Lucide；图标只做轻量品牌色强调，不使用大面积彩色底板抢层级。

## 4. 学习排行榜 Banner

「我的学习」宫格下方承接现有学习排行榜入口：

- 进入 `/courses/leaderboard`；
- 沿用 T055–T058 已确认的排行榜业务与角色状态；
- Banner 允许比普通服务入口更有视觉表现，但继续使用项目现有 token 与已有排行榜素材语言；
- 不在 `/me` 复制榜单详情，只做入口和必要的当前用户摘要。

## 5. 「更多服务」宫格

把当前纵向 `serviceEntries` 改为以 4 列宫格为主的低密度入口区。

常驻能力优先包含：

- 长期资产 `/assets`
- 我的卡券 `/benefits/wallet`
- 消息通知 `/me/notifications`
- 比赛团队 `/me/teams`
- 账号绑定 `/me/accounts`
- 帮助与客服 `/support`
- 设置中心 `/me/settings`
- 关于 `/about`

校园大使团队等**真实角色专属入口可以按状态动态出现**，不为了强行凑成固定 8 项而删除已有业务能力。

协议、隐私、授权管理等低频内容不再与主要服务同级占据 `/me` 主页面，可由设置 / 关于等二级入口承接；既有 route 不删除。

## 6. 退出登录

退出登录能力继续保留，但视觉降级：

- 不作为主要服务宫格项；
- 放在页面底部或设置页的低权重区域；
- 保留原有二次确认，不改变账号生命周期语义。

## 7. Token 与视觉纪律

必须复用 `apps/mobile/src/design-tokens.css` 当前语义：

- 页面：`background / surface / surface-subtle`
- 品牌：`primary / primary-pressed / primary-container`
- 文字：`text-primary / text-secondary / text-tertiary / text-brand`
- 边框：`border-subtle`
- 圆角：`rounded-container / rounded-control / rounded-full`
- 最小触摸尺寸：现有 mobile touch target token

禁止：

- 从参考图吸取或硬编码黑金、橙色、黄色；
- 新增另一套 `#xxxxxx` 页面主题色；
- 为“高级感”大量加黑底、厚重阴影、玻璃拟态；
- 把参考图里的功能名称直接当作核心学院需求；
- 为了视觉填充伪造学习、阅读或角色数据。

## 8. 信息层级验收

首屏视觉优先级必须清楚：

1. 用户是谁；
2. 阅读中心核心入口；
3. 我的学习；
4. 排行榜；
5. 更多服务。

不得出现以下回退：

- 顶部重新出现大标题栏「我的」；
- 身份资料重新变成大面积渐变 Banner；
- 主页面重新退化成一串带右箭头的设置列表；
- 协议 / 隐私 / 关于与课程、资产等主任务同级抢层级。

## 最低可演示路径

```text
/me
→ 点击个人资料 → /me/profile
→ 点击设置 → /me/settings
→ 我的课程 → /courses/center
→ 学习成果 → /assets/learning
→ 我的证书 → /assets/certificates
→ 学习排行榜 → /courses/leaderboard
→ 消息通知 / 卡券 / 团队 / 账号绑定 / 客服等入口均可到达既有页面
```

阅读中心单独按「路由边界」验收，不允许假链接。

## 验收

- [ ] `/me` 已移除独立 PageHeader，身份区首屏不局促。
- [ ] 头像、姓名、学校 / 专业、已有角色徽章层级清楚。
- [ ] 扫一扫与设置位于右上轻量操作区。
- [ ] 阅读中心成为首个核心业务大卡，且未复制参考图颜色。
- [ ] 我的学习使用四宫格，并全部映射真实已有能力。
- [ ] 学习排行榜 Banner 正确进入 `/courses/leaderboard`。
- [ ] 更多服务从纵向列表重构为宫格，既有关键入口未丢失。
- [ ] 退出登录能力保留且降级处理。
- [ ] 页面颜色、圆角、文字、边框、触摸尺寸均来自项目 token。
- [ ] 未新增伪造业务状态、假阅读数据、假角色或无意义 route。
- [ ] 375px / 390px / 430px 常见手机宽度下无挤压、截断或横向滚动。
- [ ] type-check / build 通过，并补 `/me` 专项 browser 回归。

## 不在本卡范围

- 新建完整阅读器 / 书架业务；
- 新建考试中心；
- 重做课程、证书、资产、团队等二级页；
- 改动排行榜 T055–T058 已确认业务规则；
- 修改账号、主体、第三方绑定等未决业务模型。
