# T056｜本校榜 / 全国榜排行榜详情页

**原派卡编号：T044（因与既有核心大使任务链编号冲突，2026-09-02 纠正为 T056）**  
**类型：原型设计卡**  
**状态：TODO**  
**范围：V1.0 正常需求**  
**前置：T055、现有用户公开资料与学校信息表达**

## 背景

学习排行榜 V1.0 同时提供本校榜与全国榜，均按本周课程学习时长排名并展示 Top 10。用户未进入 Top 10 时，也必须看到自己的排名。

## 目标

完成排行榜核心详情页，完整表达榜单切换、Top 10、我的排名、学校维度、周榜周期以及托管账户参与规则。

## 原型实现点

### 页面与榜单

- 页面标题为「学习排行榜」。
- 提供「本校榜 / 全国榜」双 Tab，并有明确选中态。
- 两个榜单均展示 Top 10。
- 榜单统一按「本周课程学习时长」由高到低表达排名关系。
- 页面明确表达当前周榜周期 / 本周时间范围。

### 本校榜条目

至少展示：排名、公开头像、公开昵称 / 网名、本周课程学习时长、校园大使 / 推荐官身份标识、点赞数与点赞入口。

本校榜可弱化学校名称，因为榜单本身已处于学校上下文。

### 全国榜条目

至少展示：排名、公开头像、公开昵称 / 网名、所属学校、本周课程学习时长、校园大使 / 推荐官身份标识、点赞数与点赞入口。

### 排名状态

- Top 1–3 有清晰但克制的头部排名视觉层级。
- 用户本人进入 Top 10 时，需要有明确本人态。
- 用户本人未进入 Top 10 时，仍需在榜单下方或固定区域展示「我的排名」。
- 「我的排名」至少展示：排名、头像、公开昵称、学校（全国榜）、本周课程学习时长和点赞状态。

## 托管账户在原型中的表达

- 数量不固定，随实际推广院校动态补充；
- 与实际推广院校对应；
- 每周动态参与本校榜与全国榜；
- 可进入 Top 10；
- 同一批账号不应长期固定霸榜；
- 真实用户达到对应课程学习时长后，可正常超过；
- 用户侧视觉与普通排行榜用户一致，不显示“托管”“模拟”等标签。

示例数据应覆盖多个推广院校，使全国榜的学校维度可验证。

## 用户资料规则

- 排行榜只使用账号系统公开昵称 / 网名与公开头像。
- 不展示真实姓名。

## UI 完成度要求

- 全部复用项目现有 design token 与组件语言。
- 列表密度、Top 3 层级、我的排名区域需达到正式高保真原型完成度。
- 参考《学习排行榜_V1.0_UI参考.png》的信息架构与构图，不要求照抄其颜色或细节。
