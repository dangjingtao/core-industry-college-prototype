# T056｜本校榜 / 全国榜排行榜详情页

**原派卡编号：T044（因与既有核心大使任务链编号冲突，2026-09-02 纠正为 T056）**  
**类型：原型设计 / 施工卡**  
**状态：REVIEW**  
**范围：V1.0 正常需求**  
**前置：T055、现有用户公开资料与学校信息表达**

## 背景

学习排行榜 V1.0 同时提供本校榜与全国榜，均按本周课程学习时长排名并展示 Top 10。用户未进入 Top 10 时，也必须看到自己的排名。

## 目标

完成排行榜核心详情页，完整表达榜单切换、Top 10、我的排名、学校维度、周榜周期以及托管账户参与规则，并达到可直接用于视觉评审的高保真完成度。

## 原型实现点

### 页面与榜单

- 页面标题为「学习排行榜」。
- 提供「本校榜 / 全国榜」双 Tab，并有明确选中态。
- 两个榜单均展示 Top 10。
- 榜单统一按「本周课程学习时长」由高到低表达排名关系。
- 页面明确表达当前周榜周期与「每周一 00:00 更新」。

### 本校榜条目

至少展示：排名、公开头像、公开昵称 / 网名、本周课程学习时长、校园大使 / 推荐官身份标识、点赞数与点赞入口。

本校榜可弱化学校名称，因为榜单本身已处于学校上下文。

### 全国榜条目

至少展示：排名、公开头像、公开昵称 / 网名、所属学校、本周课程学习时长、校园大使 / 推荐官身份标识、点赞数与点赞入口。

### 排名状态

- Top 1–3 使用明确的领奖台式头部视觉，其中 Top 1 应有更强的冠军识别度。
- 用户本人进入 Top 10 时，需要有明确本人态。
- 用户本人未进入 Top 10 时，仍需在榜单下方或固定区域展示「我的排名」。
- 「我的排名」至少展示：排名、头像、公开昵称、学校（全国榜）、本周课程学习时长和点赞状态。

## 托管账户在原型中的表达

- 数量不固定，随实际推广院校动态补充；
- 与实际推广院校对应；
- 每周动态参与本校榜与全国榜；
- 可进入 Top 10；
- 同一批账号不应长期固定霸榜；
- 真实用户达到对应课程学习时长后，可正常超过；
- 用户侧视觉与普通排行榜用户一致，不显示“托管”“模拟”等标签。

本次 mock 数据将托管样本分散在不同名次，并与普通真实用户示例混排；全国榜覆盖多个学校。`managed` 仅保留在原型数据层，不渲染到用户界面。

## 用户资料规则

- 排行榜只使用账号系统公开昵称 / 网名与公开头像。
- 不展示真实姓名。

## UI 完成度要求

2026-09-02 人工 Review 后，排行榜详情页不再受“所有视觉值必须严格映射现有 design token”的硬限制。

- 基础排版、可访问性、页面壳层、交互语义继续与项目保持一致；
- 排行榜详情允许使用**页面专属颜色、渐变、光晕、阴影、金 / 银 / 铜名次视觉、领奖台边框、Avatar Ring、自身排名高亮**等视觉值；
- 不要求上述专属视觉全部回写为全局 token，也不要求其它页面跟随采用；
- 目标优先级是：**信息层级清晰 → 视觉完成度达到正式 UI → 功能状态完整 → 再考虑 token 复用**；
- 参考已确认的学习排行榜 UI 构图：品牌 Banner → Top 3 领奖台 → 4–10 榜单卡 → 我的排名 → 页尾反馈；
- 不再以“功能齐全的普通业务列表”作为视觉验收通过标准。
