# T043｜课程首页学习排行榜模块

**类型：原型设计卡**  
**状态：TODO**  
**范围：V1.0 正常需求**  
**前置：现有课程首页、项目既有 Com Design / design token**

## 背景

新增学习排行榜。这里的“学习首页”统一指 **课程首页**，不是 App 总首页。

排行榜以周为周期，核心排名依据为本周课程学习时长。首页模块负责让用户快速感知自己的排名和榜单活跃度，并进入完整排行榜。

## 目标

在课程首页新增高完成度的排行榜摘要模块，同时保持课程浏览 / 继续学习仍是课程首页的主任务。

## 原型实现点

- 模块标题明确为「学习排行榜」。
- 位于课程首页显眼区域，但不压过课程浏览 / 继续学习主任务。
- 展示「我的本校排名」。
- 展示「本周课程学习时长」。
- 展示本校榜 Top 3 摘要。
- Top 3 至少包含：排名、公开头像、公开昵称 / 网名、本周课程学习时长。
- Top 3 中应能正常容纳「校园大使」「推荐官」身份 Badge。
- 提供明确的「查看完整排行榜」入口。
- 页面应让用户理解榜单按周更新，可通过「本周」「周榜」或本周日期范围表达。
- 所有新增组件复用项目现有 design token 与既有组件语言，不另建平行 UI 体系。

## 交互

```text
课程首页
→ 学习排行榜摘要
→ 查看完整排行榜
→ T044 排行榜详情页
```

首页 Top 3 只承担摘要作用，不在首页展开完整 Top 10。

## UI 完成度要求

- 参考项目功能设计库中的《学习排行榜_V1.0_UI参考.png》理解信息架构和完成度，不要求逐像素复刻。
- 使用项目现有 token 决定颜色、间距、圆角、文字层级与 surface。
- Top 3 不应做成过重的运营海报；它首先是课程首页中的正式产品组件。

## 验收

- [ ] 课程首页能明显发现学习排行榜。
- [ ] 用户可直接看到「我的本校排名 + 本周课程学习时长 + Top 3」。
- [ ] Top 3 可正确承载头像、网名、学习时长和身份 Badge。
- [ ] 可进入完整排行榜详情页。
- [ ] 周榜属性有明确感知。
- [ ] 新模块与现有课程首页视觉体系一致，达到正式高保真原型完成度。

## 不在本卡范围

- 日榜、月榜、历史榜；
- 学习时长奖励；
- 完整 Top 10 详情（由 T044 承接）；
- 点赞交互细节（由 T046 承接）。
