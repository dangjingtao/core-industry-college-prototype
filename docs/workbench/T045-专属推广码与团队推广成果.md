## 1. 目标

完成团队点亮后的推广阶段，并严格落实核心大使与推广伙伴不同的数据权限。

## 2. 施工范围

### 专属推广码

团队点亮后：

- 核心大使获得自己的专属推广码；
- 每名推广伙伴获得自己的专属推广码；
- 后续新加入已点亮团队的推广伙伴也立即获得专属推广码；
- 未点亮团队不开放专属推广码。

原型需要模拟业务结果：

```text
专属推广码
→ 下载 / 注册链路
→ 新用户注册成功
→ 记录活动 + 团队 + 推广人员
→ 形成 1 个有效新增
```

中保真阶段验证归因业务语义，不要求实现真实 App Store / Android 安装归因服务。

### 核心大使权限

提供「团队推广成果」入口，至少展示：

- 团队人数；
- 团队有效新增总数；
- 每名团队人员对应的有效新增数量；
- 必要推广明细占位。

### 推广伙伴权限

只能看到所属团队、活动状态和自己的专属推广码。

不得看到自己的有效新增、团队总有效新增、其他成员数据或排行榜。

## 3. 验收

- [ ] 未点亮团队没有可用专属推广码；
- [ ] 点亮后全员都有独立推广码；
- [ ] 模拟新用户注册后，只给对应推广人员增加 1 个有效新增；
- [ ] 已注册用户不重复计为有效新增；
- [ ] 核心大使能查看团队成果；
- [ ] 推广伙伴完全看不到个人及团队成果数字。
