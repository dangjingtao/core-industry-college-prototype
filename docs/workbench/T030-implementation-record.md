## Owner 已确认

- 学生 / 参赛团队承诺书保留；
- 指导老师承诺书保留；
- 不做页面内电子签；
- 两份都下载打印并手写签字；
- 签字后都需要上传回系统；
- 两份文件都上传后，承诺书步骤才算完成。

## 原型实现

新增：

- `apps/pc/src/registration-portal/T030CommitmentPage.tsx`

接入：

- `/registration-portal/commitment`

原型页面只表达：

```text
生成两份承诺书
→ 下载
→ 打印 / 手写签字
→ 上传签字后的文件
→ 两份均已上传
→ 完成报名
```

其中：

- 指导老师承诺书继续使用文案“下载指导老师承诺书模板”；
- 指导老师承诺书复用当前团队 / 项目信息；
- 指导老师信息允许后置，不阻塞前期团队报名；
- 上传按钮为中保真状态模拟，不实现真实文件存储。

## 有意不做

当前是产品原型，不继续扩展：

- 电子签；
- OCR / 签名真实性识别；
- 文件多版本；
- 文件审核流；
- 复杂老师端签署系统；
- 后端文件生命周期。

后续 T032 如需教师查看承诺书，只承接必要的审核展示，不因此扩展本卡。
