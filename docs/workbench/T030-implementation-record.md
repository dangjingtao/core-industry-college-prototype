# T030｜承诺书体系收口｜原型记录

> 状态：Owner 决策已确认 / 原型已收口  
> 日期：2026-08-24  
> 正式设计：`docs/product/09-commitment-letter-flow.md`

## Owner 已确认

- 学生 / 参赛团队承诺书保留；
- 指导老师承诺书保留；
- 不做页面内电子签；
- 两份都下载打印并手写签字；
- **签字后不需要上传回系统。**

## 原型实现

页面：

- `apps/pc/src/registration-portal/T030CommitmentPage.tsx`
- `/registration-portal/commitment`

当前原型流程：

```text
生成两份承诺书
→ 下载
→ 打印 / 手写签字
→ 按赛事材料要求线下使用
→ 无需回传系统
→ 完成报名
```

其中：

- 指导老师承诺书继续使用文案“下载指导老师承诺书模板”；
- 指导老师承诺书复用当前团队 / 项目信息；
- 指导老师信息允许后置，不阻塞前期团队报名；
- 原型不再显示“上传签字文件”按钮；
- 不再用“上传完成”作为报名完成条件。

## 本次修正

前一版曾按“签字后上传回系统”实现了两份上传状态。Owner 最新明确：承诺书不需要回传。

已撤销：

- 学生承诺书上传按钮；
- 指导老师承诺书上传按钮；
- “两份均已上传”状态；
- 上传完成才可完成报名的限制。

当前完成条件仅为：两份承诺书已生成，可供下载。

## 有意不做

当前是产品原型，不继续扩展：

- 电子签；
- OCR / 签名真实性识别；
- 文件上传 / 回传；
- 文件多版本；
- 文件审核流；
- 复杂老师端签署系统；
- 后端文件生命周期。

T032 教师工作台无需为承诺书增加文件审核能力。
