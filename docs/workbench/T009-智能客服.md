# T009｜智能客服原型

**类型：施工卡**  
**状态：已完成**  
**优先级：P1**

## 背景

旧原型包含客服对话、请求人工客服。新原型已实现智能客服对话页，并在首页提供悬浮圆形入口。

## 目标

实现一个中保真智能客服对话原型，支持欢迎语、热门问题、智能回复与转人工入口。

## 已交付

- [x] 首页悬浮圆形入口：右下角固定「智能客服」按钮，点击进入 `/support/chat`。
- [x] 客服对话页：
  - 欢迎语：进入页面自动展示 AI 欢迎消息。
  - 热门问题：默认展示 5 个热门问题标签，点击后直接作为用户问题发送。
  - 消息列表：用户消息（右侧气泡）与 AI 回复（左侧气泡）。
  - 输入框：支持手动输入并回车发送。
  - 智能回复：基于关键词匹配的 mock 知识库回复（报名 / 赛事 / 证书成绩 / 简历 / 实习机会 / 人工）。
- [x] 请求人工客服：
  - 页面底部「请求人工客服」文字入口。
  - 右上角耳机图标按钮。
  - 点击后弹出模态框，展示企业微信客服二维码占位（明确说明正式二维码由运营配置，不伪造真实连接）。
- [x] 帮助中心入口：对话页底部提供「查看帮助中心」链接跳转 `/support`。
- [x] 路由注册：`/support/chat` 已注册并通过 mobile typecheck / build。

## 禁止

- 不伪造真实人工客服在线状态。
- 不构造无法解释答案来源的 AI 回复。
- 不因为入口延后就把客服页做成孤立页面；URL 与路由保持一致。

## 验收动线

```text
首页 → 右下角悬浮客服按钮 → /support/chat
  → 欢迎语 + 热门问题
  → 点击热门问题 → 智能回复
  → 手动输入问题 → 关键词匹配回复
  → 右上角耳机 / 底部「请求人工客服」→ 企业微信二维码弹窗
  → 查看帮助中心 → /support
```
