# T009｜智能客服原型

**类型：施工卡**  
**状态：待执行**  
**优先级：P1**

## 背景

旧原型包含客服对话、请求人工客服。新原型无客服入口。产品侧决定先实现智能客服原型，入口可稍后添加。

## 目标

实现一个中保真智能客服对话原型，支持常见问题问答与转人工入口。

## 最低交付

- [ ] 客服对话页：消息列表（用户 / 客服）、输入框、快捷问题推荐。
- [ ] 常见问题入口：按场景分类（报名 / 赛事 / 课程 / 证书 / 账号）。
- [ ] 智能回复：使用预设 FAQ 进行关键词匹配回复（mock，不接入真实 LLM）。
- [ ] 请求人工客服：明确最终渠道入口（如企业微信福利官 / 在线表单），按 F003 外部 handoff 模式处理，不伪造真实客服连接。
- [ ] 会话状态：历史会话列表（本地 mock）。
- [ ] 入口延后添加，但页面本身可独立访问并通过路由注册。

## 禁止

- 不伪造真实人工客服在线状态。
- 不构造无法解释答案来源的 AI 回复。
- 不因为入口延后就把客服页做成孤立页面；URL 与路由保持一致。

## 验收动线

```text
（入口待加，当前可直接访问 /support/chat）
  → 客服对话页
  → 点击快捷问题 → 智能回复
  → 输入问题 → 匹配回复 / 未匹配提示
  → 转人工 → 企微福利官 / 反馈表单 handoff
```
