# T042｜徽章系统设计

> 类型：产品决策 / 设计
> 状态：待确认（设计文档已产出，进入产品评审）
> 日期：2026-08-25
> 前置：F04 Decision A（学力值经济）、D03（任务体系）、T011 / T024（课程体系）、T034（课程考试 / 发证公信力）、T008（可信空间）、T017（长期简历 / 成长档案）
> 来源：2026-08-25 产品会会议笔记

---

## 1. 背景与问题

当前 App 缺乏一个「能持续积累、可展示、有实际作用」的长期成就载体。现有可积累对象分散在课程、权益、证书、赛事成绩里，彼此没有统一的呈现与规则，学生缺少「下一个目标是什么」的持续牵引。

徽章系统的核心判断来自会议笔记第 8 条：

> 徽章即成就。

反方：单纯成就只有展示意义而无实际意义。因此本设计不把徽章做成「只收集不生效」的荣誉墙，而是让它成为：可信证书的门槛、运营大礼包的门槛、简历里的可信能力证据。

---

## 2. 目标用户

| 用户 | 关系 | 期望价值 |
| --- | --- | --- |
| 学生（长期账号） | 核心用户 | 获得「看得见、能积累、可炫耀」的成长记录，形成持续使用 App 的目标驱动 |
| 新用户 / 新手任务期 | 强引导对象 | 通过新手任务完成第一个高级徽章，快速建立成就感和平台心智（会议笔记第 4 条） |
| 参赛学生 | 强关联 | 徽章与赛事身份、成绩、项目进度联动，赛前有目标、赛后有沉淀 |
| 用人单位 / 企业 | 间接 | 通过可信证书（徽章门槛）看到一个可解释、可验证的能力证据；不替代企业自主判断，不构造不可见评分 |
| 微专业学习者（企业与高校合办、强制学习） | 强关联 | 在固定学习进程通过关卡小测领取高级徽章，课程结束后参加线上小考，形成学习-考核-发证的完整闭环 |
| 学校 / 企业 / 微专业运营方 | 规则参与方 | 徽章作为微专业课程完成度与发证公信力的载体（会议笔记第 6 条）；企业与高校合办，共同设定学习与考核规则 |
| 平台运营 | 配置方 | 徽章定义、素材、发放规则、大礼包门槛由运营侧配置，研发只提供基座（会议笔记第 7 条） |

---

## 3. 期望效果

1. **激活与留存**：把低频的「参赛 / 学习 / 打卡」转化为高频的「收集徽章」目标驱动；新用户在新手任务阶段完成第一个高级徽章，形成第一次正反馈。
2. **行为引导**：用徽章显式激励 APP 行为（打卡、看广告、完善资料、学习课程、通过小测、参赛、推进项目进度），且这些行为已有真实出口，不造假按钮。
3. **长期资产沉淀**：徽章进入长期账号的可信空间与简历表达，比赛结束后徽章持续存在（符合「比赛会结束，资产不结束」原则）。
4. **可信证书公信力**：微专业可信证书的获得规则透明、可解释——必修课程 + 一定数量低级 / 高级徽章 + 关卡小测 + 结业线上小考，替代「说不清的评分」，提升发证公信力（会议笔记第 3、5 条）。
5. **运营承接**：运营侧「大礼包」（大额优惠 / 礼券）以徽章为门槛发放，成本可控（带门槛，不无差别发放），研发提供基座即可（会议笔记第 7 条）。
6. **微专业学习闭环**：企业与高校合办的微专业采用强制学习模式，在固定学习进程发放高级徽章，领取前须通过关卡小测；课程结束举行线上小考，形成「学习 → 关卡小测 → 高级徽章 → 结业小考 → 可信证书」的完整闭环。

---

## 4. 徽章分级模型

徽章不强制绑定课程，来源可以是：APP 行为 / 课程 / 赛事身份 / 进度 / 小测等（会议笔记第 1 条）。

| 维度 | 低级徽章 | 高级徽章 |
| --- | --- | --- |
| 获得途径 | APP 行为 / 日常小任务（如观看激励广告、每日打卡、完善资料、参加活动） | 课程学习完成 / 小测通过 /（学力值 + APP 行为）组合 |
| 门槛 | 低，易获得 | 高，需真实投入 |
| 数量 | 多，覆盖高频行为 | 少，代表真实能力 |
| 时效 | 可短期 / 可循环 | 长期有效 |

设计要点：

- 低级徽章负责「高频刺激 + 行为习惯养成」，高级徽章负责「能力证明 + 长期资产」；
- 一个行为可同时满足多个徽章条件时，由规则引擎按配置归一发放，不复制真相源；
- 徽章达成规则对学生透明、可解释（符合「不构造不透明 AI 评分」原则）。

---

## 5. 徽章 → 可信证书链路

按会议笔记第 3 条：

```text
微专业（企业与高校合办，强制学习；课程托管于 App，事实源）
   ├─ 必修课程完成（更高阶）
   ├─ 若干低级徽章（品相：低级）
   ├─ 若干高级徽章（固定学习进程发放，领取前须过关卡小测）
   └─ 结业线上小考通过
        ↓
   可信证书（最高级）
```

即：可信证书 = 必修课程 + 规定数量的低级徽章 + 规定数量的高级徽章 + 关卡小测 + 结业线上小考通过。具体「几个低级 / 几个高级 / 哪些必修课程 / 小测与考试规则」由产品与运营定，研发按规则引擎实现。

**事实源约束**：微专业课程托管于 App（原则上，会议笔记第 6 条），由企业与高校合办。徽章引用课程 / 赛事 / 任务 / 权益 / 小测与考试记录，通过稳定 ID 派生，不复制对象形成第二真相源。

---

## 5.1 小测机制

微专业采用强制学习模式，小测分为两类，职责不同（用户补充）：

| 维度 | 关卡小测 | 结业线上小考 |
| --- | --- | --- |
| 时机 | 固定学习进程节点，伴随高级徽章发放 | 课程全部结束后 |
| 目的 | 校验该学习进程的知识掌握，是领取该节点高级徽章的前置条件 | 校验整体课程学习成果，是获得可信证书的前置条件 |
| 关系 | 小测通过 → 领取该节点高级徽章 | 小考通过（连同徽章条件）→ 获得可信证书 |
| 可重试 | 待确认（建议允许重考，是否限次待定） | 待确认（是否限次 / 是否影响发证时间待定） |

关键规则（待产品确认后冻结）：

1. 高级徽章在固定学习进程发放，**领取前必须先通过对应关卡小测**；
2. 关卡小测未通过 → 高级徽章不可领取，学生可复习后重测；
3. 课程结束后的线上小考为结业考试，通过后方可进入可信证书发放；
4. 小测与小考成绩作为徽章 / 证书达成事实记录，通过稳定 ID 挂到学习记录，不单独复制真相源；
5. 企业与高校合办方共同设定考核规则，平台提供考试能力基座。

## 6. 入口与动线建议

1. **我的 → 徽章墙（成就总览）**
   - 展示已获得 / 未获得徽章、获得条件与进度；
   - 徽章按「低级 / 高级 / 可信证书」分层展示。
2. **任务中心 / 新手任务**
   - 新手任务引导用户完成第一个高级徽章（会议笔记第 4 条）；
   - 每日打卡、看广告等行为可展示「可获得徽章」提示。
3. **课程详情 / 微专业学习进程 / 赛事详情 / 赛事工作区**
   - 显示与该课程 / 赛事关联的徽章及当前进度；
   - 微专业固定学习进程节点展示「关卡小测」入口，通过后领取高级徽章；
   - 课程结束展示「结业线上小考」入口，通过后进入可信证书发放。
4. **可信空间 / 简历表达**
   - 学生自主选择将徽章作为可信能力证据展示到简历（符合「学生决定哪些可信经历进入简历」原则）。

## 7. 成本与收益（简）

### 成本

- **研发成本：中**
  - 徽章数据模型与规则引擎（条件判定、发放、幂等）；
  - 徽章墙 UI 与各入口联动点；
  - 与课程 / 赛事 / 任务 / 权益 / 可信证书的数据接入。
- **运营成本：中**
  - 徽章定义、素材、文案、发放规则、大礼包配置。

### 收益

- 提升学生激活与留存（游戏化目标驱动 + 新手首个高级徽章正反馈）；
- 强化可信证书公信力（可解释达成规则，替代不可见评分）；
- 支撑运营侧大礼包 / 权益发放，且成本可控（带徽章门槛）；
- 增强长期资产价值，赛事结束后徽章与证书继续沉淀。

---

## 8. 依赖与不破坏原则

- 徽章不持有第二份 session / identities / 学力值 / 任务真相源；
- 徽章通过稳定 ID 引用课程、赛事、任务、权益记录派生，不复制对象；
- 学力值是否真实发放、徽章奖励与学力值经济的关系，等 F04 Decision A；
- 徽章与任务体系（D03）的归属关系，等 F04 Decision C；
- 不构造对学生不透明的评分；徽章达成规则透明可解释；
- 徽章不是某一赛事专属，赛事结束后徽章与可信资产继续存在。

---

## 9. 待决策项（施工前需产品确认）

1. 具体徽章清单：低级 / 高级各定义哪些徽章、覆盖哪些行为与来源；
2. 可信证书门槛数值：必修课程范围、低级 / 高级徽章数量；
3. **关卡小测规则**：哪些固定学习进程节点发放高级徽章、对应小测范围、题量与及格线、是否限重考、重考冷却；
4. **结业线上小考规则**：考试范围、题量与及格线、是否限重考、重考是否影响发证时间、是否收取费用；
5. 学力值是否真实发放，徽章奖励与 F04 Decision A 的关系；
6. 徽章与 D03 任务体系 / F04 Decision C 的归属关系；
7. 徽章是否过期 / 降级 / 循环（如「连续打卡」类徽章）；
8. 「大礼包」的金额范围、徽章门槛、发放与核销方式（运营侧）；
9. 微专业课程托管范围、企业与高校合办的权责、发证主体（学校 / 企业 / 平台 / 联合）；
10. 徽章是否展示于简历 / 可信空间，展示规则与隐私。
