# T010｜通知中心

**类型：施工卡**  
**状态：待执行**  
**优先级：P0**

## 背景

首页右上角已有消息通知图标，但缺少消息列表二级页面。旧原型包含站内信、系统通知、赛事通知列表。

## 目标

完善首页右上角小铃铛的通知中心，提供消息列表、分类查看与详情。

## 最低交付

- [ ] 首页右上角通知图标：未读红点/数字 badge。
- [ ] 通知列表页：顶部 Tab（全部 / 系统 / 赛事 / 课程 / 企业），按时间倒序，已读/未读状态。
- [ ] 通知卡片：标题、摘要、时间、类型标签、已读状态。
- [ ] 通知详情页：完整内容、相关操作入口（如跳转到赛事 / 课程 / 可信空间）。
- [ ] 一键已读 / 清空已读。
- [ ] 空状态：无通知时的引导页。
- [ ] 消息设置入口（可跳转到 T014 设置中心）。

## 禁止

- 不伪造真实推送到达。
- 不与 F04 的第三方账号/消息通道混淆。
- 不因为未接入真实消息服务就删掉入口。

## 验收动线

```text
首页 → 右上角铃铛
  → 通知列表页（Tab 切换 / 一键已读）
  → 通知详情 → 跳转相关业务页
```
