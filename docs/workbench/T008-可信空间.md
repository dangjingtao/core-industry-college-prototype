# T008｜可信空间补充

**类型：施工卡（依赖 F02 可信凭证基础）**  
**状态：已完成**  
**优先级：P0**

## 背景

旧原型可信空间包含：可信数字教育身份领取、领取成功、我的证书、证书详情、快速验真、帮助中心。新原型「可信成果/长期资产」已基于 F02 实现上述能力，并保留成绩查询入口。

## 目标

保持首页「可信成果」原有入口不变（四宫格快捷入口），确保 `/assets` 长期资产页完整承接旧原型可信空间的核心能力，并临时保留成绩查询入口。

## 已交付

- [x] 首页「可信成果」保持四宫格快捷入口不变：课程 / 权益 / 可信成果 / 合作企业。
- [x] 点击「可信成果」进入 `/assets` 长期资产总览。
- [x] `/assets` 已承载旧原型可信空间能力：
  - 可信数字教育身份领取：`/assets/education-identity`（核验/领取/保存/下载）
  - 领取成功反馈：证书与身份领取后页面顶部显示领取成功提示
  - 我的证书：`/assets/certificates`
  - 证书详情：`/assets/certificates/:certificateId`（领取/保存/下载/验真）
  - 成绩查询：`/assets/results`
  - 成绩详情：`/assets/results/:resultId`
  - 快速验真：`/assets/verification`（验真码 / 二维码 / PDF/OFD 文件 / 官方 handoff）
  - 帮助中心入口：`/assets` → 可信空间服务 → 帮助中心（跳转 `/support`）
- [x] 通过 mobile typecheck / build。
