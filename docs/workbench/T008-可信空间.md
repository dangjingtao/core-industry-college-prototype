# T008｜可信空间补充

**类型：施工卡（依赖 F02 可信凭证基础）**  
**状态：已完成（首页入口层）**  
**优先级：P0**

## 背景

旧原型可信空间包含：领取成功、我的证书、证书详情、快速验真、帮助中心。新原型「可信成果/长期资产」已基于 F02 实现证书列表、证书详情（领取/保存/下载/验真）、成绩列表/详情、快速验真（验真码/扫码/文件/官方 handoff）等完整能力，但首页仅通过 4 宫格的一个图标进入，功能入口不够直观。

## 目标

把可信空间的核心能力直接暴露在首页「可信成果」区域，并临时增加成绩查询入口。

## 已交付

- [x] 首页「可信成果」从单一图标扩展为独立功能卡片。
- [x] 首页可信成果快捷入口：
  - 我的证书：显示证书记录总数，若有可领取证书显示「N 张可领取」。
  - 成绩查询：显示赛事结果事实数量，临时入口跳转 `/assets/results`。
  - 快速验真：跳转 `/assets/verification`。
  - 查看全部：跳转 `/assets` 长期资产总览。
- [x] 课程 / 权益 / 合作企业保留在 3 宫格快捷入口中。
- [x] 通过 mobile typecheck / build。

## 待后续确认（不在本卡范围）

- 证书领取成功后的独立成功页：当前为状态变更（claimable → claimed）+ 详情页提示，是否恢复旧原型的独立成功页待产品确认。
- 可信空间独立帮助中心：旧原型的帮助中心已合并到 `/support`，是否单独恢复待产品确认。
- 赛事结束后从赛事工作区/通知引导到可信空间领取证书：属于赛事生命周期通知策略，待 F04 / 通知中心统一设计。

## 禁止

- 不把可信空间做成单纯的文件管理器；主心智仍是「可信凭证」。
- 不伪造真实验真结果；扫码/文件验真使用 mock，状态明确。
- 不破坏 F02 已建立的可信事实只读边界。

## 验收动线

```text
首页 → 可信成果卡片
  → 我的证书 → /assets/certificates
  → 成绩查询 → /assets/results
  → 快速验真 → /assets/verification
  → 查看全部 → /assets
```
