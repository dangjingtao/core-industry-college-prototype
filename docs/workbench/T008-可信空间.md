# T008｜可信空间补充

**类型：施工卡（依赖 F02 可信凭证基础）**  
**状态：待执行**  
**优先级：P0**

## 背景

旧原型可信空间包含：领取成功、我的证书、证书详情、快速验真、帮助中心。新原型「可信成果/长期资产」仅作概览，缺少证书领取、验真、帮助完整流程。成绩查询与证书领取流程也整合进可信空间。

> 依赖前置：F02 已补充验真入口、保存/下载、外部官方验证出口。本卡在 F02 基础上把可信空间扩展为完整模块。

## 目标

把可信空间建设为赛事/学习证书的统一领取、查看、验真、下载中心，并集成成绩查询。

## 最低交付

- [ ] 可信空间首页：证书分类（赛事证书 / 学习证书 / 成绩单）、最近领取、待领取提示。
- [ ] 我的证书列表页：按类型/时间筛选，证书卡片（名称、颁发方、时间、状态）。
- [ ] 证书详情页：证书信息、证书编号、二维码、下载按钮、保存到本地。
- [ ] 领取成功页：领取结果反馈、查看证书按钮、分享/保存入口。
- [ ] 快速验真页：验真码输入、扫码验真入口、文件验真入口、官方验真平台 handoff（沿用 F002）。
- [ ] 可信空间帮助中心：常见问题、如何验真、证书丢失怎么办。
- [ ] 成绩查询页：成绩列表、成绩详情（按赛事/时间聚合），从可信空间首页入口进入。
- [ ] 证书领取流程：赛事结束后从赛事工作区/通知引导到可信空间领取，生成证书并沉淀到长期资产。

## 禁止

- 不把可信空间做成单纯的文件管理器；主心智仍是「可信凭证」。
- 不伪造真实验真结果；扫码/文件验真使用 mock，状态明确。
- 不破坏 F02 已建立的可信事实只读边界。

## 验收动线

```text
首页 → 可信空间入口
  → 可信空间首页
  → 我的证书 / 待领取 / 成绩查询
  → 证书详情 → 下载 / 分享
  → 快速验真 → 验真结果
```

## 依赖

- F02｜企业可信信息 + 可信凭证完整能力
