```text
技能入口
→ 动态答题
→ 生成确认
```

必须统一表达：

- [ ] 动态答题：单选 / 多选，AI 根据回答动态调整后续问题的原型反馈。

- [ ] 补充说明。

- [ ] 任务进度允许离开页面，并明确“完成后通过站内消息通知”。
- [ ] 成果详情保留 Mockplus 已有的编辑 / 分享 / 队长提交确认等主要动作。

## 二、S1｜项目洞察｜Mockplus 119–122

### 动态答题

以 Mockplus“选品评分”为当前真实交互实例：

- [ ] 问题逐步呈现，不改成一屏大表单。
- [ ] 包含单选 / 多选示例，例如价格区间、选品优势等。
- [ ] 展示“AI 正在分析回答，准备下一题”的动态问答反馈。
- [ ] 保留作答完善度、补充信息等原型模式。

### 生成确认

- [ ] 标题 / 任务语义按 Mockplus 项目洞察实例实现。
- [ ] 展示问答摘要与 AI 提取核心信息。
- [ ] 展示主观补充。
- [ ] 展示预计算力与冻结提示；`820 / 100` 等仅为示例数据。
- [ ] 支持确认生成 / 返回修改。

### 任务进度

- [ ] 展示生成进度与阶段状态。
- [ ] 已读取参赛档案、已检查问答材料、正在生成建议、质量检查。
- [ ] 可离开页面，完成后站内消息通知。
- [ ] 原型允许“模拟完成”。

### 成果详情

以 Mockplus“选品评分小报告”为基线：

- [ ] 核心发现 / 关键结论。
- [ ] 薄弱环节。
- [ ] 优先行动清单。
- [ ] 详细分析。
- [ ] 报告评级 / 多维评分表达。
- [ ] 编辑 / 分享 / 队长提交确认。

**不得把我此前任务卡里“赛道推荐卡 + 待验证清单”当成必须照做的 Mockplus 原生页面；如保留只能作为产品语义补充，不能覆盖现有成果结构。**
