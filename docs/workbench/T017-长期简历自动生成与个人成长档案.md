# T017｜长期简历自动生成与个人成长档案

**类型：施工卡（依赖 F03 / F04 部分决策）**  
**状态：部分完成**  
**优先级：P1**

## 当前原型完成度

- [x] `/me/resume` 长期简历页已实现自动聚合客观事实：
  - 赛事经历（来自 `identities[]` + `workspaceData` 团队角色）；
  - 学习成果（来自已完成课程 + 考试状态）；
  - 证书（来自 `certificates` 已领取）。
- [x] 系统事实标注为「系统事实」并只读；用户仅可选择是否进入简历，不可修改事实本身。
- [x] 个人优势、教育经历（时间/主修课程/在校经历）可编辑，且页面明确区分系统读取与手动补充。
- [x] 赛事结束后经历不会消失，identities 使用 `active` / `revoked` 全量历史，不绑定当前赛事身份。
- [ ] 「我的」页面未将长期简历作为独立核心入口，仅通过「长期资产」→「下一步」或「我的」中无直接入口访问，层级未提升。
- [ ] 简历页标题仍为「长期简历」，未强化为「个人成长档案 / 长期简历」心智。

## 背景

当前 `/me/resume` 长期简历已支持结构化字段（手机号、学校、专业、学历、毕业时间、在校经历等），由 F03 实现。

昨天下班前内部会议明确：

> 长期简历将作为核心功能，根据用户的行为（如学习、参赛）自动生成一份客观的个人成长档案，不绑定特定赛事身份。

本卡将长期简历从「可编辑表单」提升为「自动生成 + 可编辑呈现」的核心成长档案。

## 目标

将长期简历打造为核心功能入口，自动聚合用户行为产生的客观事实，形成不绑定当前赛事身份的个人成长档案。

## 最低交付

### 入口强化

- [ ] 在「我的」页面提升 `/me/resume` 长期简历的层级，使用资产卡或独立强入口展示。
- [ ] 简历页标题与心智从「在线简历」升级为「个人成长档案 / 长期简历」。

### 自动生成内容

- [ ] 自动聚合以下客观事实（只读，来源稳定）：
  - 教育身份：学校、专业、学历（来自 F01 StudentProfile）；
  - 课程学习：已完成课程、考试成绩、获得证书（来自 T011 课程深度功能）；
  - 赛事经历：参赛赛事、团队角色、项目成果、比赛成绩（来自 identities[] / CompetitionIdentity / Workshop results）；
  - 可信空间：证书、成绩报告、可信数字教育身份（来自 T008 可信空间）；
  - 机会投递：投递记录与状态（来自 Public Platform applications）。
- [ ] 每项事实标注来源与状态，例如「课程完成 · 商业分析基础」、「三创赛 · 队长 · 省赛银奖」。
- [ ] 赛事结束后，相关经历、成绩、证书继续保留，不因赛事生命周期结束而消失。

### 呈现与编辑边界

- [ ] 系统可信事实只读，不可由用户修改；
- [ ] 简历呈现层（如个人优势、在校经历、主修课程）可编辑，并明确区分「自动同步」与「手动补充」；
- [ ] 提供「导出 / 分享 / 用于投递」等下一步操作入口。

### 不绑定当前赛事身份

- [ ] 成长档案读取 `identities[]` 全量历史，不假设用户只有当前一个赛事身份；
- [ ] 当前赛事上下文仅作为最近动态展示，不替代完整档案。

## 禁止

- 不构造不透明的 AI 人才评分或能力雷达。
- 不伪造未发生的行为数据。
- 不把成长档案绑定到单一赛事身份。
- 不创建第二份学生主档、课程记录或赛事身份真相源。

## 验收动线

```text
我的 → 长期简历 / 个人成长档案 → /me/resume
  → 顶部：教育身份摘要（来自 StudentProfile）
  → 自动聚合：课程完成、考试成绩、证书
  → 自动聚合：赛事经历、团队角色、项目成果
  → 自动聚合：投递记录、关注企业
  → 可编辑区：个人优势、在校经历、主修课程
  → 操作：导出 / 分享 / 用于投递
```
