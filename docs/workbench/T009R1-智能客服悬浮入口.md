# T009R1｜智能客服入口改为右下角悬浮蓝色窗口与交互优化

**类型：施工卡（T009 方向修订）**  
**状态：部分完成**  
**优先级：P1**

## 当前原型完成度

- [x] 首页右下角已有蓝色悬浮客服入口（`fixed bottom-20 right-4`，`bg-primary` 圆形按钮，链接至 `/support/chat`）。
- [x] `/support/chat` 客服对话页已存在，支持：
  - 欢迎语与热门问题；
  - 基于关键词规则的知识库回复（报名、赛事、证书、简历、实习、人工）；
  - 右上角/底部人工客服入口，点击弹出企业微信二维码占位弹窗。
- [ ] 入口目前仅在首页，未全局常驻。
- [ ] 热门问题未按场景分组，且无「后续可接入大模型」的明确提示文案。

## 背景

T009 已实现智能客服对话页，并在首页提供悬浮圆形入口。

昨天下班前内部会议要求：

1. 客服入口改为页面右下角悬浮的蓝色客服窗口，确保用户能便捷找到；
2. 客服基于知识库回复；对于无答案的问题，后续可接入大模型；
3. 优化客服界面的交互细节。

## 目标

将客服入口从首页局部按钮升级为全站右下角悬浮蓝色窗口，优化对话页交互，并保持中保真可演示。

## 最低交付

- [ ] 全站右下角悬浮蓝色客服入口按钮（不仅限于首页），常驻于 `PublicShell` 或全局布局中。
- [ ] 入口视觉：蓝色主色调、悬浮胶囊/圆形窗口，不遮挡底部导航关键操作。
- [ ] 点击入口后进入 `/support/chat` 客服对话页（或展开浮窗对话层）。
- [ ] 客服对话页交互优化：
  - 欢迎语更贴合当前产品（赛事、实习、课程、权益）。
  - 热门问题按场景分组（报名 / 赛事 / 课程 / 证书 / 实习机会 / 账号 / 人工）。
  - 消息气泡、输入框、发送按钮视觉与动线优化。
  - 无知识库答案时，提示「已记录，后续可接入大模型/转人工客服」。
- [ ] 保留转人工客服入口（企业微信二维码占位），不伪造真实在线状态。
- [ ] 通过 mobile `typecheck` / `build`。

## 禁止

- 不伪造真实人工客服在线状态。
- 不构造无法解释答案来源的 AI 回复。
- 不因为入口全局化就破坏现有路由与 URL 一致性。

## 验收动线

```text
任意页面 → 右下角悬浮蓝色客服入口
  → 进入 /support/chat
  → 欢迎语 + 场景化热门问题
  → 点击问题 / 手动输入 → 知识库匹配回复
  → 无答案 → 提示接入大模型或转人工
  → 右上角/底部 → 请求人工客服 → 企微二维码弹窗
```
