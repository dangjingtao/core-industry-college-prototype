## 原型变化

1. 登录从“选择学校 / 选择老师”改为账号 + 密码；
2. 页面明确账号由系统分配，教师无需注册；
3. 登录后固定显示当前授权学校；
4. 团队列表按授权学校过滤，不提供跨校统计 / 跨校筛选；
5. 详情只保留团队、项目、成员等审核必要信息；
6. 待审核团队仅提供“通过 / 驳回”两种动作；
7. 已处理团队只展示审核记录；
8. 承诺书不回传，因此教师端不增加承诺书审核；
9. 已核对学生 App 路由，没有教师审核入口。
