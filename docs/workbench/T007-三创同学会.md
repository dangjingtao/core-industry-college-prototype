# T007｜三创同学会（原「赛友风采」板块）

**类型：施工卡**  
**状态：已完成**  
**优先级：P1**

## 背景

旧原型「首页-赛友风采」包含赛友故事详情、公众号内容详情、更多列表页、投稿页。新原型无社区内容/投稿/赛友故事入口。经产品侧调整，该板块更名为「三创同学会」，参考外部设计稿整合为三大模块：

- 赛友风采（合并原「三创风采」优秀项目展示 + 「优秀校友」主页）
- 创·项目（找合作 / 招聘 / 资源置换 / 经验分享）
- 赛事助力（学力值任务、助力统计、助力记录）

## 目标

建立「三创同学会」内容板块，所有内容由运营后台统一上传，学生端只做展示与轻互动。

## 最低交付

- [x] 三创同学会首页：顶部 Tab（赛友风采 / 创·项目 / 赛事助力）。
- [x] 赛友风采：
  - 第十六届优秀团队卡片列表（项目图占位、奖项、描述、标签、学校、团队规模）。
  - 奖项筛选：全部 / 金奖 / 银奖 / 铜奖 / 专项奖。
  - 历届优秀赛友网格展示，点击查看更多进入完整列表页 `/stories/alumni`。
  - 赛友主页：头像、学校/届/角色、认证、奖项、标签、关注按钮、获奖项目、备赛经验分享。
- [x] 创·项目：
  - 按类型展示找合作 / 招聘 / 资源置换 / 经验分享卡片。
  - 每张卡片含标题、描述、作者、点赞/评论数。
  - 移除学生端「去发布」入口，页面说明内容由运营后台上传。
- [x] 赛事助力：
  - 我的学力值展示。
  - 已助力人数、累计学力值、已筹资金统计。
  - 今日任务列表，点击「去完成」模拟增加学力值并记录。
  - 助力记录列表。
- [x] `/stories/submit` 改为运营后台上传说明页，不开放学生投稿。
- [x] 首页保留「三创同学会」入口卡片。
- [x] 通过 mobile typecheck / build。

## 产品决策记录

- **2026-08-18**：所有优秀案例、赛友风采、项目需求均由运营后台统一上传，学生端不允许投稿。

## 禁止

- 不引入真实后端内容发布流程；学生端不开放投稿/发布功能。
- 不在无内容时伪造真实用户数据；使用占位示例内容并明确标注「示例数据」。
- 不为了社交而引入关注/粉丝关系（关注按钮仅为原型占位，不形成持久社交图谱）。
- 不自行定义学力值经济模型（数值只做界面展示，真实规则待 F04 确认）。

## 验收动线

```text
首页 → 三创同学会入口
  → 赛友风采：优秀团队 / 奖项筛选 / 历届优秀赛友 → 赛友主页
  → 创·项目：分类卡片列表
  → 赛事助力：学力值 / 统计 / 今日任务 / 助力记录
```
