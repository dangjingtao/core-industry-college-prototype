# T007｜三创同学会（原「赛友风采」板块）

**类型：施工卡**  
**状态：待执行**  
**优先级：P1**

## 背景

旧原型「首页-赛友风采」包含赛友故事详情、公众号内容详情、更多列表页、投稿页。新原型无社区内容/投稿/赛友故事入口。经产品侧调整，该板块更名为「三创同学会」，承载参赛学生故事、公众号内容聚合与投稿。

## 目标

建立「三创同学会」内容板块，包含：

1. 赛友故事列表与详情；
2. 公众号内容聚合与详情；
3. 投稿入口（学生投稿自己的赛友故事或内容）。

## 最低交付

- [x] 三创同学会首页/列表页：顶部 Tab（赛友故事 / 公众号精选 / 投稿入口），卡片列表，支持上拉加载。
- [x] 赛友故事详情页：作者信息、故事正文、相关标签、点赞/分享入口。
- [x] 公众号内容详情页：标题、来源、发布时间、正文、原文外链（参考 F003 外部 handoff 模式）。
- [x] 投稿页：标题、正文、配图上传（mock）、提交按钮、投稿须知。
- [x] 投稿成功页/状态反馈。
- [x] 与首页入口衔接。

## 禁止

- 不引入真实后端内容发布流程；投稿状态使用本地 mock。
- 不在无内容时伪造真实用户数据；使用占位示例内容并明确标注「示例数据」。
- 不为了社交而引入关注/粉丝关系（属于 F04 后续决策范围）。

## 验收动线

```text
首页 → 三创同学会入口
  → 列表页（Tab 切换）
  → 赛友故事详情 / 公众号内容详情
  → 投稿页 → 提交 → 成功反馈
```
