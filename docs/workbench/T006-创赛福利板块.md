# T006｜创赛福利板块补充

**类型：施工卡（依赖 F04 Decision A）**  
**状态：待执行**  
**优先级：P0**

## 背景

旧原型「首页-创赛福利」包含日常任务、核心任务、学力值规则、学力值明细、兑换中心。新原型当前仅在权益页展示已有权益，缺少学力值的获取/消耗规则说明、收支流水与兑换行为。

> 依赖前置：F04 Decision A 必须先确认学力值经济模型（积分 vs 成长分 / 是否拆分）。本卡只建立页面结构与原型流程，不自行决定数值规则。

## 目标

补全创赛福利板块，使学生能：

1. 查看学力值规则；
2. 查看学力值收支明细；
3. 在兑换中心用学力值/算力兑换课程、权益、道具；
4. 完成日常任务与核心任务并获得学力值。

## 最低交付

- [ ] 学力值规则页：获取规则、消耗规则、有效期/过期规则（规则文案用占位，等待 F04 决策）。
- [ ] 学力值明细页：收入/消耗/过期流水，支持按时间/类型筛选。
- [ ] 兑换中心首页：课程、权益、道具分类，支持搜索与分类筛选。
- [ ] 兑换详情页：商品介绍、所需学力值/算力、兑换按钮、兑换确认弹窗。
- [ ] 任务专区页：日常任务列表、核心任务列表、任务进度、去完成入口。
- [ ] 任务详情页（如需要）：任务说明、奖励、完成条件。
- [ ] 所有页面与现有「我的学力值」入口衔接，不破坏现有权益页结构。

## 禁止

- 不自行定义学力值是「可消费积分」还是「成长分」；规则文案用占位，待 F04 决策后替换。
- 不恢复旧 D03 任务体系与创赛工坊 Task Runtime 的混淆关系。
- 不新建独立的任务 Store；若涉及任务状态，使用现有 session / applications 边界。

## 验收动线

```text
首页 → 创赛福利入口
  → 学力值规则（可阅读规则占位文案）
  → 学力值明细（流水列表 + 筛选）
  → 兑换中心（分类列表 → 兑换详情 → 确认兑换）
  → 任务专区（日常/核心任务 → 去完成）
```

## 依赖

- F04 Decision A｜学力值经济模型
- F04 Decision C｜D03 任务体系（日常/核心任务的业务归属）
