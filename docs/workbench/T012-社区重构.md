# T012｜社区重构

**类型：施工卡（待产品明确）**  
**状态：待决策 / 待执行**  
**优先级：P1**

## 背景

旧原型社区模块包含社区公告、企业任务、工商信息、实训机会详情、投递进度跟踪。新原型把社区相关能力打散到「机会」、「企业」、「我的」等页面，缺少统一社区入口与公告/企业任务/投递进度等能力。

> 本卡在产品侧进一步明确社区定位前，先做页面补齐与入口梳理，不做大架构改动。

## 目标

补齐社区相关缺失能力，明确社区入口承载的内容范围。

## 最低交付

- [ ] 社区公告页：平台公告 / 赛事公告 / 企业公告聚合列表与详情。
- [ ] 企业任务页：企业发布的专属任务列表、任务详情、报名/完成/获得学力值流程（依赖 F04 Decision C）。
- [ ] 企业工商信息：在企业详情页补充工商信息展示（F02 A 已覆盖，本卡确认社区入口可见）。
- [ ] 实训机会详情：项目实践分类下的岗位/实训详情页，包含报名/进度/成果入口。
- [ ] 投递进度跟踪：在「我的」投递记录中增加投递状态流转（已投递 / 初筛 / 面试 / offer / 不合适）。
- [ ] 社区首页（待明确）：确定社区底部 Tab 是否保留，若保留则整合公告、企业任务、实训机会入口。

## 禁止

- 不在社区中强行引入社交互动（点赞/评论/关注）——属于 F04 后续差异化决策。
- 不恢复旧社区视觉布局 1:1。
- 不自行决定企业任务与学力值/任务体系的关系；依赖 F04 Decision C。

## 验收动线

```text
（社区入口待明确）
  → 社区公告 → 公告详情
  → 企业任务 → 任务详情 → 报名/完成
  → 实训机会 → 详情 → 报名/进度
  → 我的 → 投递记录 → 投递进度
```

## 依赖

- F02｜企业可信信息（工商信息）
- F04 Decision C｜D03 任务体系（企业任务归属）
