**类型：设计梳理 + 施工卡**

## 2026-09-02 最新设计方向

本节为 T014 当前最新设计基线，优先级高于本卡早期“统一纵向入口列表”以及同日第一版“阅读中心核心卡”的描述。

`/me` 改为个人中心 Dashboard。参考成熟个人中心页面的**布局结构、信息节奏和模块分组**，不复制参考页面的具体功能和黑金 / 橙色视觉。核心学院颜色、文字、圆角、边框、状态和触摸尺寸继续以现有 Com Design / `apps/mobile/src/design-tokens.css` 为准。

### 产品事实纠正

**核心学院当前没有阅读功能。** 参考页面中的「阅读中心」只是参考图中的业务内容，不属于核心学院需求。`/me` 不得出现阅读中心、阅读占位、阅读统计或“功能接入中”等解释性 UI。

新的主页面层级：

```text
个人身份区
→ 长期资产核心卡
→ 我的学习四宫格
→ 学习排行榜 Banner
→ 更多服务 4×2
→ 协议 / 隐私 / 授权低权重直达
→ 退出登录
```

### 新设计语言

- **第一层：账号身份。** 顶部直接展示头像、姓名 / 昵称、学校 / 专业和已有角色徽章；不再使用独立 `PageHeader title="我的"`，也不再用大面积资料 Banner 占首屏。
- **右上轻操作。** 扫一扫与设置放在身份区右上；编辑资料由身份区进入 `/me/profile`。
- **第二层：长期资产核心卡。** 强视觉业务卡由现有 `/assets` 承接，可展示当前 store 中真实的学习 / 证书 / 成绩摘要；不得硬编码或伪造用户数据。
- **第三层：我的学习。** 高频学习能力使用 4 列宫格，入口映射真实 route：课程、学习记录、证书、赛事成绩。
- **排行榜入口。** 学习排行榜作为「我的学习」后的独立 Banner，进入 `/courses/leaderboard`，沿用 T055–T058 已确认业务。
- **第四层：更多服务。** 常用服务使用 4×2 宫格；动态校园推广团队可独立展示，不为了固定格数删除能力。
- **低频能力降权不删除。** 用户协议、隐私政策、授权管理仍需从 `/me` 直接可达，但可使用页面后段的轻量文本入口，不与主要任务同权重。
- **退出登录。** 保留二次确认和原账号语义，放在页面底部低权重区域。
- **图标与色彩。** 使用项目现有图标体系与 semantic token；禁止从外部参考图吸色或新增另一套页面主题色。
- **圆角与间距。** 沿用现有 `rounded-container / rounded-control`、mobile touch target 与 spacing token；普通 Card 不靠厚重阴影建立层级。
- **状态标签。** 只表达真实已有事实，不创造新的角色 / 业务状态。
- **赛事衔接。** `/me/teams` 只做跨赛事团队汇总；成员维护继续带 `competitionId` 回赛事 workspace。

> T014 早期规则「当前服务统一使用纵向入口列表」不再约束 `/me` 主页面；二级设置页仍可使用列表模式。

具体施工与验收要求见 `docs/workbench/tasks/T059-my-page-dashboard-redesign.md`。

## 背景

「我的」页面承担长期账号身份和个人能力入口。旧原型 24 页中包含消息通知中心、卡包、在线简历、比赛团队管理、主体管理、第三方绑定、协议与隐私、设置中心、帮助与反馈等能力。部分能力已在 F03 中处理（退出登录、简历结构化、团队维护部分）。

本卡职责：

1. 总结「我的」页面设计语言；
2. 补齐并持续承接已有功能入口与二级页面；
3. 保证后续视觉重构不破坏 route 和业务真相源。

## 禁止

- 不自行决定 D08 主体管理业务模型。
- 不恢复旧「我的」24 页 1:1，按当前设计语言重新组织。
- 不因为功能多就牺牲信息层级。
- 不把参考图中的功能名称直接当作核心学院需求。
- **不出现阅读中心或任何阅读占位。**
- 不从参考图复制黑金 / 橙色视觉或硬编码新的页面主题色。
- 不为统计卡或 Banner 伪造业务数据。
- 不为了视觉重构删除已有入口、route 或改变账号、资产、赛事、团队的业务语义。
