**类型：设计梳理 + 施工卡**

**优先级：P1**  
**后续施工：T059｜「我的」页面 Dashboard 化重构**

## 2026-09-02 设计方向修订

本节为 T014 当前最新设计基线，**优先级高于本卡早期“统一纵向入口列表”的旧描述**。

本轮确认：`/me` 不再继续做成偏设置页的「资料大卡 + 服务列表 + 关于列表」，而改为**个人中心 Dashboard**。

参考成熟个人中心页面的布局结构、信息节奏和模块分组，但只借鉴布局，不复制参考图的黑金 / 橙色视觉。核心学院所有颜色、文字、圆角、边框、状态、触摸尺寸继续以现有 Com Design / `apps/mobile/src/design-tokens.css` 为准。

新的主页面层级：

```text
个人身份区
→ 核心业务大卡（阅读中心）
→ 我的学习四宫格
→ 学习排行榜 Banner
→ 更多服务宫格
→ 低频账号操作
```

### 新设计语言

- **第一层：账号身份。** 顶部直接展示头像、姓名 / 昵称、学校 / 专业和已有角色徽章；不再使用独立 `PageHeader title="我的"`，也不再用大面积渐变资料 Banner 占据首屏。
- **右上轻操作。** 扫一扫与设置放在身份区右上，不额外占一整行；编辑资料由身份区进入 `/me/profile`。
- **第二层：核心业务大卡。** 首个强视觉卡承接「阅读中心」，用品牌 token 建立层级；不复制参考图黑色、橙金按钮，也不为视觉效果伪造阅读数据。
- **第三层：我的学习。** 学习相关高频能力优先使用 4 列宫格，入口必须映射当前真实 route；不得为了贴参考图凭空创建“我的考试”等不存在的独立业务。
- **排行榜入口。** 学习排行榜作为「我的学习」后的独立 Banner，进入 `/courses/leaderboard`，沿用 T055–T058 已确认的榜单业务和角色状态。
- **第四层：更多服务。** 通知、卡券、长期资产、比赛团队、账号绑定、客服、设置、关于等改为宫格入口；真实角色专属入口可以按状态动态出现，不为固定格数删除业务能力。
- **第五层：低频设置。** 协议、隐私、授权管理等继续保留既有 route，但不再与学习、资产、团队等主任务同级占据 `/me` 首屏；由设置 / 关于等二级页面承接。
- **退出登录。** 保留二次确认和原账号语义，但降为页面底部或设置页低权重操作。
- **图标。** 继续使用 Lucide，不另造一套插画式系统图标。
- **色彩。** 主页面只使用项目语义 token；禁止从外部参考图吸色或新增另一套页面主题色。
- **圆角与间距。** 沿用现有 `rounded-container / rounded-control`、mobile touch target 与 spacing token；不靠厚重阴影或大块黑底制造“高级感”。
- **状态标签。** 只表达真实已有事实：参赛中、审核中、历史、权限已回收、已绑定、未绑定、已授权、校园大使等，不创造新的角色 / 业务状态。
- **赛事衔接。** `/me/teams` 只做跨赛事团队汇总；成员维护必须带 `competitionId` 回到对应赛事 workspace。

> T014 早期规则「当前服务使用统一入口列表；每行图标、名称、说明、右箭头」自 2026-09-02 起不再约束 `/me` 主页面。二级设置页仍可继续使用列表模式。

具体施工与验收要求见 `docs/workbench/tasks/T059-my-page-dashboard-redesign.md`。

## 背景

「我的」页面当前已包含基础资料、赛事/项目经历、学习成果、证书记录、投递记录、关注企业。旧原型 24 页中还包含消息通知中心、卡包、比赛团队管理、主体管理、第三方绑定、协议与隐私、设置中心、帮助与反馈等能力。部分能力已在 F03 中处理（退出登录、简历结构化、团队维护部分）。

本卡原始职责：

1. 总结「我的」页面原型设计语言（信息层级、卡片模式、入口组织方式）；
2. 补齐剩余功能入口与二级页面。

2026-09-02 起，功能承接继续沿用；主页面视觉和信息架构按上方新设计语言执行。

## 目标

统一「我的」页面设计语言，并补齐消息通知、卡包、团队管理、设置、帮助反馈、协议隐私等能力；同时保证后续视觉重构不破坏既有 route 和业务真相源。
