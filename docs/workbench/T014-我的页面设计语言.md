# T014｜我的页面设计语言总结 + 功能补齐

**类型：设计梳理 + 施工卡**  
**状态：待执行**  
**优先级：P1**

## 背景

「我的」页面当前已包含基础资料、赛事/项目经历、学习成果、证书记录、投递记录、关注企业。旧原型 24 页中还包含消息通知中心、卡包、比赛团队管理、主体管理、第三方绑定、协议与隐私、设置中心、帮助与反馈等能力。部分能力已在 F03 中处理（退出登录、简历结构化、团队维护部分）。

本卡要求：
1. 总结「我的」页面原型设计语言（信息层级、卡片模式、入口组织方式）；
2. 补齐剩余功能入口与二级页面。

## 目标

统一「我的」页面设计语言，并补齐消息通知、卡包、团队管理、设置、帮助反馈、协议隐私等能力。

## 最低交付

### 设计语言总结
- [ ] 输出「我的」页面设计语言文档：
  - 信息层级（头像/昵称/身份卡、功能入口、长期资产、设置）
  - 卡片组件模式（资产卡、入口列表、状态标签）
  - 图标/色彩/间距规范
  - 与首页、赛事工作区等其他页面的衔接方式

### 功能补齐
- [ ] 消息通知中心入口与二级页（可与 T010 通知中心共用页面）。
- [ ] 卡包页：优惠券/兑换券/权益卡管理，空状态处理。
- [ ] 比赛团队管理：我加入的团队列表、切换团队、团队详情（赛事期维护见 F03）。
- [ ] 第三方绑定：邮箱/微信/企业微信绑定入口（依赖 F04 Decision B，先占位）。
- [ ] 协议与隐私：用户协议、隐私政策、授权管理页面。

- [ ] 主体管理入口（D08 未决前可展示但标记为「即将开放」或 blocked）。
