## 统一产品事实

1. 排行榜按周统计。
2. V1.0 同时提供本校榜和全国榜。
3. 两个榜单均展示 Top 10。
4. 用户未进入 Top 10 时仍需看到「我的排名」。
5. 唯一排名依据为本周课程学习时长。
6. 用户侧展示账号公开昵称 / 网名与公开头像，不展示真实姓名。
7. 校园大使与推荐官均为 V1.0 正常需求，并提供正式身份 Badge。
8. 托管账户不规定固定数量，随实际推广院校动态补充；每周动态参与本校榜和全国榜。
9. 托管账户可以进入 Top 10，但不应长期固定霸榜；真实用户达到学习时长条件后可正常超过。
10. 点赞属于 V1.0 正常需求：支持点赞、取消、重新点赞、自赞限制和周周期；点赞不影响排名。
11. 课程首页展示排行榜摘要与 Top 3，并可进入完整排行榜。
12. 学习时长奖励当前不属于 V1.0 范围。

## 统一 UI / 原型要求

- 本批任务是原型施工，不提前建设生产级后端或复杂排行基础设施。
- 参考项目功能设计库中的《核心学院_学习排行榜_V1.0_功能设计.docx》与《学习排行榜_V1.0_UI参考.png》理解业务与构图。
- UI 参考图不是独立视觉规范；颜色、字号、间距、圆角、surface、触控区等以仓库现有 design token 和组件语言为准。
- 完成度需要接近正式 UI，而不是线框占位。
- 关键交互和状态应可在原型中真实触发，或通过 Prototype Runtime / 明确 mock 切换。
