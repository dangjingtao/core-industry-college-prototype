## 最低交付

### 技能矩阵与入口
- [ ] 创赛工坊首页：技能矩阵展示（S1-S6 卡片），当前赛事阶段推荐下一步任务。
- [ ] 技能包详情页：技能介绍、适用阶段、所需算力、开始任务按钮。
- [ ] 算力明细页：算力余额、收支流水、消耗记录。
- [ ] 历史成果页：用户使用 AI 技能包生成的历史输出成果列表。

### 标准任务闭环（每个技能包）
- [ ] 信息采集页：测试/点选/量表/上传，按技能包要求采集。
- [ ] 生成确认页：队长确认消耗算力，启动 OPC 技能运行。
- [ ] 任务进度页：异步运行状态、预计时间、可离开页面。
- [ ] 成果详情页：OPC 产出报告/内容/数据，分块展示，逐块修改/采用。
- [ ] 成果版本管理（S3/S5 涉及文案/图/PPT 多版本时）：保存版本、对比、采用。

### 按技能包的具体页面
- [ ] S1 项目洞察：赛道倾向测试页、选品评分量表、竞品点选对比、目标用户多选、洞察报告页。
- [ ] S2 项目诊断：真实性自测、商业模式勾选、成员分工测评、证据上传确认、诊断报告页。
- [ ] S3 内容代运营：平台/目标点选、卖点排序、风格量表、商品信息确认、内容方案生成页（标题/详情/脚本/话术/配图）。
- [ ] S4 数据复盘：数据上传（Excel/截图）、指标勾选、异常点选、目标设定、经营周报页。
- [ ] S5 赛事冲刺：评分预检自评、材料勾选、路演时长选择、模拟问答、赋能成果报告页。
- [ ] S6 职业规划：职业倾向测评、能力自评量表、发展方向点选、职业规划报告页。

## 禁止

- 不偏离参考设计中的六阶段技能矩阵。
- 不把创赛工坊做成全局 AI 工具箱；必须依附于具体赛事上下文。
- 不伪造 OPC 真实运行；异步处理与产物回流使用 mock 数据，状态明确。
- 不引入开放式对话输入作为主交互；严格使用结构化测评与点选。
- 不新建第二份赛事身份/项目档案真相源；使用 workspace 已有项目与成员信息。

## 验收动线

```text
赛事工作区 → 创赛工坊入口
  → 技能矩阵首页
  → 选择技能包 / 按阶段推荐
  → 信息采集（测试/点选/上传）
  → 队长确认消耗算力 → 启动运行
  → 任务进度（可离开）
  → 成果回流 → 分块查看/修改/采用
  → 历史成果 / 算力明细
```
