# T034｜课程考试 / 发证公信力｜原型记录

> 状态：原型主流程已施工  
> 日期：2026-08-24  
> 正式规则：`docs/product/13-course-exam-and-credential-rules.md`

## 本轮关键修正

旧课程页存在一个明显问题：考试通过后统一写成“可信教育认证电子证书”，导致普通课程、新手内容与高价值课程没有证书成本和公信力层级差异。

T034 改为三档：

```text
仅学习记录
普通电子证书
可信证书
```

可信证书不再是课程默认结果。

## 原型施工

新增：

- `apps/mobile/src/features/long-term-assets/T034CoursePages.tsx`

覆盖主路由：

- `/courses`
- `/courses/center`
- `/courses/:courseId`
- `/courses/:courseId/assessment`
- `/courses/:courseId/achievement`
- `/assets/certificates/:certificateId`（普通课程证书会被拦截到普通证书详情；可信 / 赛事证书继续走可信详情）

课程学习播放器 `/courses/:courseId/learn` 继续复用原实现。

## 当前可见效果

### 课程列表

- 高价值可信课程单独突出；
- 显示“高学力值 + 可信证书”；
- 普通课程只显示普通电子证书；
- 未配置证书的课程显示“不发证”。

### 付费课程详情

- 兑换前可试看第 1 节；
- 试看不扣学力值；
- 再决定是否兑换完整课程。

### 考试

- 考试前直接显示次数限制；
- 原型采用会议示例“每月 2 次”；
- 未通过后显示剩余次数；
- 次数耗尽后禁用继续提交。

### 成果 / 证书

- 普通电子证书不显示验真码 / 官方验真；
- 可信课程通过后才进入可信证书领取；
- 没有证书的课程只显示长期学习记录。

## 原型示例

当前仅把 `AI 电商智能体实战` 作为可信课程示例，因为它是现有目录最高学力值档（250）。

这只是为了验证“高门槛课程才配可信证书”的产品表达，不锁定最终课程名单或价格。
