## 1. 目标

把「核心大使计划」接入现有 PC 管理端控制面，让运营可以创建活动、管理学校招募码、查看团队与推广成果，并记录简单团队激励状态。

本卡不得另起一套独立 Admin Shell，也不得把学生 App 页面搬到 PC。

## 2. 施工范围

首版信息层级保持：

```text
活动列表
→ 活动详情
→ 团队详情
```

### 活动列表

展示：

- 活动名称；
- 开始 / 结束时间；
- 活动状态；
- 覆盖学校数；
- 核心大使数；
- 已点亮团队数；
- 有效新增总数。

### 创建 / 编辑活动

支持：

- 活动名称；
- 开始 / 结束时间；
- 参与学校；
- 大使申请表字段；
- 活动条款。

点亮门槛首版固定为「1 位核心大使 + 3 位推广伙伴」，不做复杂规则编辑器。

### 学校与招募码

- 每所参与学校生成独立的大使招募二维码；
- 二维码关联活动 + 学校；
- 支持查看 / 下载二维码；
- 可查看学校产生的大使、团队和推广数据。

### 活动详情

顶部展示覆盖学校、核心大使、已点亮团队、推广伙伴、有效新增等整体数据。

下方团队列表至少展示：核心大使、学校、团队状态、团队人数、有效新增、激励状态，并支持基础筛选。

### 团队详情

展示：

- 核心大使基本 / 申请信息；
- 学校、团队状态、团队人数；
- 成员列表；
- 团队有效新增总数；
- 每位成员有效新增；
- 必要推广明细；
- 简单团队激励状态。

## 3. 不做

- 不新建代理中心 / 结算中心 / 独立数据中心；
- 不计算团队内部个人分成；
- 不给推广伙伴逐人结算；
- 不复制账号、学校或团队真相源；
- 不修改现有赛事官方后台语义来硬塞本活动。

## 4. 实现记录（2026-08-26）

- 新增 `apps/pc/src/admin/T046AmbassadorConsole.tsx`，接入现有 PC 控制面壳与 `/admin/ambassadors` 路由。
- 活动列表 → 活动详情 → 团队详情连续可用；活动详情投影覆盖学校、核心大使、点亮团队、推广伙伴、有效新增与学校招募码。
- 支持创建 / 编辑活动，学校增删同步对应招募码；覆盖学校按活动配置统计；活动状态按日期进入 `upcoming / active`。
- 支持配置申请表字段与活动条款版本；团队详情展示核心大使申请信息、成员级有效新增、推广明细与简单激励处理状态。
- 共享 demo seed 提供进行中活动、已点亮团队、4 位成员和有效新增，团队详情在原型中可直接演示。
- 学校招募二维码由 `qrcode` 前端生成真实 SVG 矩阵；payload 为 `VITE_PUBLIC_SITE_URL/ambassadors?code=...`，与 T044 核心大使申请入口一致；下载按钮下载同一份二维码 SVG。
- `AmbassadorStateProvider` 继续作为 `@core/shared` 中保真共享模型，不复制账号、学校或团队真相源。
- 验证：`npm run typecheck --workspace @core/pc`、`npm run build --workspace @core/pc`、`npm run e2e --workspace @core/pc -- tests/t046-ambassador.spec.ts` 均通过。
