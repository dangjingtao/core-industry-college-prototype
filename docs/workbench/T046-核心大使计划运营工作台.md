# T046｜PC 运营后台：核心大使计划运营工作台

> 类型：施工  
> 状态：可施工  
> 日期：2026-08-26  
> 前置：T043、PC01、PC-BD01  
> 来源：`docs/product/18-campus-ambassador-prd.md`

---

## 1. 目标

把「核心大使计划」接入现有 PC 管理端控制面，让运营可以创建活动、管理学校招募码、查看团队与推广成果，并记录简单团队激励状态。

本卡不得另起一套独立 Admin Shell，也不得把学生 App 页面搬到 PC。

## 2. 施工范围

首版信息层级保持：

```text
活动列表
→ 活动详情
→ 团队详情
```

### 活动列表

展示：

- 活动名称；
- 开始 / 结束时间；
- 活动状态；
- 覆盖学校数；
- 核心大使数；
- 已点亮团队数；
- 有效新增总数。

### 创建 / 编辑活动

支持：

- 活动名称；
- 开始 / 结束时间；
- 参与学校；
- 大使申请表字段；
- 活动条款。

点亮门槛首版固定为「1 位核心大使 + 3 位推广伙伴」，不做复杂规则编辑器。

### 学校与招募码

- 每所参与学校生成独立的大使招募二维码；
- 二维码关联活动 + 学校；
- 支持查看 / 下载二维码；
- 可查看学校产生的大使、团队和推广数据。

### 活动详情

顶部展示覆盖学校、核心大使、已点亮团队、推广伙伴、有效新增等整体数据。

下方团队列表至少展示：核心大使、学校、团队状态、团队人数、有效新增、激励状态，并支持基础筛选。

### 团队详情

展示：

- 核心大使基本 / 申请信息；
- 学校、团队状态、团队人数；
- 成员列表；
- 团队有效新增总数；
- 每位成员有效新增；
- 必要推广明细；
- 简单团队激励状态。

## 3. 不做

- 不新建代理中心 / 结算中心 / 独立数据中心；
- 不计算团队内部个人分成；
- 不给推广伙伴逐人结算；
- 不复制账号、学校或团队真相源；
- 不修改现有赛事官方后台语义来硬塞本活动。

## 4. 验收

- [ ] 核心大使计划进入现有 PC 控制面导航 / 业务入口；
- [ ] 可创建活动并配置多所学校；
- [ ] 每所学校有独立招募码；
- [ ] App 产生的大使、团队人数、点亮状态、有效新增在 PC 正确投影；
- [ ] 活动列表 → 活动详情 → 团队详情连续可用；
- [ ] PC 可查看成员级推广成果；
- [ ] 激励只记录简单处理状态，不出现个人分账能力。
