## 1. 目标

完成学生从学校招募码进入，到申请核心大使、招募推广伙伴并点亮团队的 App 链路。

## 2. 施工范围

### 核心大使申请

- 扫描学校大使招募码进入申请；
- 未登录用户先登录 / 注册，完成后回到原申请流程；
- 展示大使申请表和条款确认；
- 提交成功后直接获得「核心大使 · 待点亮」；
- 生成并展示团队招募码。

### 推广伙伴加入

- 新用户可注册后加入；
- 未绑定本期其它团队的老用户可直接加入；
- 已绑定其它团队时阻止重复加入；
- 加入后显示所属团队和「推广伙伴」身份；
- 活动期间不提供退队 / 换队入口。

### 团队点亮

- 大使页展示组队进度；
- 1 位核心大使 + 3 位推广伙伴后自动点亮；
- 大使状态由「待点亮」变为「已点亮」；
- 点亮后仍允许继续招募更多推广伙伴。

首版尽量复用状态页面，不为每个状态复制一套页面。

## 3. 验收

- [x] 学校招募码 → 登录 / 注册 → 申请 → 待点亮可走通；
