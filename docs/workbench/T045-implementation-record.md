# T045｜专属推广码与团队推广成果｜实现记录

> 日期：2026-08-26
> 状态：已完成（App 中保真）

## 交付

- 未点亮团队不签发个人推广码；
- 团队点亮后为核心大使与全部推广伙伴签发独立推广码；
- 后续加入已点亮团队的推广伙伴立即获得个人推广码；
- 团队页生成可扫描的个人 QR SVG，payload 精确指向该成员的推广落地路由；
- 专属推广落地页模拟新用户注册，并记录活动、团队和推广人员；
- 同一期活动内的新账号归因去重，已注册账号和团队现有成员不计数；
- 核心大使查看团队人数、有效新增总数、成员成果和归因明细；
- 推广伙伴只看活动 / 团队状态与自己的推广码，不展示成员列表、成果数字或排名；
- 保持中保真边界，不实现真实安装归因、注册服务和财务结算。
