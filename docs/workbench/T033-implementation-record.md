## 本轮修改

原应用中心会把所有已启用模拟模块自动铺成“互动体验”宫格，视觉与产品心智都更像模拟器仓库。

现改为：

```text
应用中心
→ 经营小挑战
→ 校园饮品店
→ 复用现有 H5 Simulation Host
```

首个体验明确为“校园饮品店”：选菜单 → 做活动 → 扛高峰，约 3 分钟一局，可重复体验。

## 原型边界

- 继续保留“应用中心”名称；
- 其它模拟模块保留在现有 registry，不删除；
- 应用中心当前只突出一个轻互动入口；
- 不新增游戏详情系统或第二套宿主；
- 暂不显示学力值奖励；
- 不进入正式成绩 / 长期能力资产。
