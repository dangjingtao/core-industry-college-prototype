## 业务方确认方向

正式需求不是一次性的经营小游戏，而是：

> **「我的创业小店」虚拟养成**

映射关系：

```text
签到 / 答题 / 上课 → 进货
拉新 → 客流
日常活跃 → 店铺成长等级
养成等级 → 权益折扣
```

每个用户一间虚拟小店，把“打开 App”包装成“回来经营我的店”，与三创赛“创业实战”主题结合。

## 对上一版 T033 的修正

上一版把“校园饮品店”3 分钟经营挑战作为主互动入口，这与业务方正式需求不一致。

现已改为：

```text
应用中心
→ 我的创业小店
→ 敬请期待 / 规划中占位
```

页面只展示核心玩法映射，不再跳转现有 Simulation Host。

## 排期边界

业务方明确：

- P2；
- 10 月后评估上线；
- 前期不依赖该模块。

因此当前原型不实现：

- 真正店铺养成；
- 库存 / 客流 / 等级计算；
- 权益折扣联动；
- 每日任务与成长数值；
- 与签到、课程、答题、拉新数据的真实接线。

仓库已有 H5 模拟器继续保留为技术储备，不作为 T033 当前正式产品方案。
