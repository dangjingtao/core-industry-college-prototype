# T006｜创赛福利板块

**类型：施工卡（依赖 F04 学力值经济模型决策）**  
**状态：已完成（首页入口 + 页面结构）**  
**优先级：P1**

## 背景

旧原型「创赛福利」板块包含学力值余额、明细、免费福利领取、兑换中心等功能。新原型原「权益」页面较单薄，需要补全为完整的创赛福利板块。

由于 F04 尚未对学力值经济模型（积分 vs 成长分 vs 其他）作出最终决策，本卡仅实现页面结构与交互流程，所有学力值数额、收入/支出记录、兑换消耗均为**原型占位数据**，待 F04 决策后替换真实服务。

## 目标

按旧原型能力补齐「创赛福利」板块，保留首页四宫格入口，新增学力值展示、明细、全部免费福利、兑换中心、兑换详情。

## 已交付

- [x] 首页四宫格入口：「创赛福利」（原「权益」）保留，跳转 `/benefits`。
- [x] `/benefits` 创赛福利首页：
  - 学力值余额卡片（原型占位 1280）。
  - 「查看明细」入口。
  - 「免费福利」「兑换中心」快捷入口。
  - 推荐免费福利：展示 2 条可领取 / 待使用权益。
  - 推荐兑换：展示 2 条可兑换商品。
- [x] `/benefits/credits` 学力值明细：
  - 余额、收入/支出汇总。
  - 收支明细列表（原型占位数据）。
- [x] `/benefits/free` 全部免费福利：
  - 全部 / 可领取·待使用 / 历史 三种筛选。
  - 已补充两条平台合作券作为首推免费福利：
    - 腾讯地图出行打车券
    - 淘宝闪购无门槛外卖券
  - 券类权益支持 `externalUrl` 跳转 H5 领取页，详情页提供手机号输入框占位。
- [x] `/benefits/exchange` 兑换中心：
  - 顶部搜索栏：支持按名称/简介搜索可兑换项目。

  - 每个分类保留顶部 tab 栏：默认 / 销量 / 学力值。
  - 商品网格展示：名称、简介、学力值消耗、已兑换人数、库存状态。
- [x] `/benefits/exchange/:exchangeId` 兑换详情：
  - 商品信息、库存、我的学力值。
  - 「确认兑换」按钮与兑换成功提示（原型模拟，不扣减真实余额）。
- [x] 路由注册：`/benefits`、`/benefits/free`、`/benefits/exchange`、`/benefits/exchange/:exchangeId`、`/benefits/credits`。
- [x] 通过 mobile typecheck / build。

## 待后续确认（不在本卡范围）

- 学力值经济模型：积分、成长分还是其他形态（F04）。
- 学力值获取来源：任务、课程、报名等行为与学力值的对应关系（F04 / D03）。
- 兑换中心商品、库存、价格、排序策略是否由运营后台配置。
- 兑换后是否扣减余额并生成长期资产记录。

## 禁止

- 不自行决定学力值是积分还是成长分。
- 不恢复旧日常/核心/企业任务及学力值奖励（D03 仍冻结）。
- 不伪造真实余额扣减或真实商品发放。
- 不把兑换中心做成与现有权益系统冲突的独立经济系统。

```text
首页 → 创赛福利（四宫格）→ /benefits

  → 免费福利 → /benefits/free
  → 兑换中心 → /benefits/exchange
    → 兑换详情 → /benefits/exchange/:exchangeId
      → 确认兑换 → 成功提示
```
