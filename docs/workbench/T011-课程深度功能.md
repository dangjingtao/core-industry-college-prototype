# T011｜课程深度功能

**类型：施工卡（部分依赖 F04 Decision A）**  
**状态：待执行**  
**优先级：P1**

## 背景

旧原型学院/课程模块包含课程成就/徽章、课程考试、课程证书、课程兑换、学习排行榜。新原型课程详情页只有目录与继续学习，缺少深度学习闭环。

## 目标

在现有课程列表/详情基础上，补充学习成就、考试、证书、兑换与排行榜，形成完整学习闭环。

## 最低交付

- [ ] 课程成就页/模块：学习过程中获得的成就/徽章列表、获取条件、已获/未获状态。
- [ ] 课程考试入口：章节考试 / 结课考试，考试页（倒计时、题目进度、提交）。
- [ ] 考试结果页：得分、正确率、错题回顾、获得学力值/证书提示。
- [ ] 课程证书：完成课程后获得学习证书，沉淀到可信空间 / 长期资产。
- [ ] 课程兑换：课程详情页展示「免费」或「需 X 学力值/算力兑换」，兑换流程与确认（依赖 F04 Decision A）。
- [ ] 学习排行榜：课程维度 / 全站维度的学习时长/完成数排行。
- [ ] 课程详情页增加考试、证书、排行榜入口。

## 禁止

- 不自行决定学力值是否可消费；兑换逻辑依赖 F04 Decision A，先用占位规则。
- 不为了游戏化而虚构排行榜真实用户数据。
- 不破坏课程进度与学时的事实边界。

## 验收动线

```text
学院 → 课程详情
  → 继续学习 / 章节目录
  → 课程考试 → 考试页 → 结果页
  → 课程成就 → 徽章详情
  → 课程证书 → 领取到可信空间
  → 学习排行榜
```

## 依赖

- F04 Decision A｜学力值经济模型（兑换逻辑）
- T008｜可信空间（证书领取）
