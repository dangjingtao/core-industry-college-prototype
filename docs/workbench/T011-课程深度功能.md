# T011｜课程深度功能

**类型：施工卡（部分依赖 F04 Decision A）**  
**状态：已完成（课程中心、详情页、学习-考试-证书闭环；学习排行榜除外）**  
**优先级：P1**

## 背景

旧原型学院/课程模块包含课程成就/徽章、课程考试、课程证书、课程兑换、学习排行榜。新原型课程详情页只有目录与继续学习，缺少深度学习闭环。

## 目标

在现有课程列表/详情基础上，补充学习成就、考试、证书、兑换与排行榜，形成完整学习闭环。

## 已交付

- [x] 学院首页 `/courses`：
  - 顶部自动轮播图推荐课程。
  - 「课程中心」入口卡片。
  - 「在学课程 / 已学完课程」Tab 切换。
- [x] 课程中心 `/courses/center`：
  - 顶部搜索栏，支持按名称/简介搜索。
  - 左侧分类标签栏：全部 / OPC / 美妆新零售 / 乡村振兴 / AI电商 / 商业分析 / 企业项目。
  - 顶部 value tab：全部 / 免费 / 需学力值。
  - 顶部 sort tab：默认 / 最热。
  - 课程网格卡片展示封面、分类、价值标签、学习状态。
- [x] 课程数据模型扩展：
  - 新增 `category`（内容维度）与 `entitlement`/`cost`（价值维度）。
  - 新增 `description`、`chapterCount`、`cover` 等字段。
  - 课程初始均为未报名状态；种子账号保留已报名课程以验证在学/已学完动线。
- [x] 课程详情页 `/courses/:courseId`：
  - 顶部视频占位区 + 课程基本信息（课时、节数、一句话简介）。
  - Tab 栏：简介、目录、成就。
  - 简介 Tab：详细课程描述 + 报名/兑换按钮。
  - 目录 Tab：章节目录列表 + 继续学习/开始学习按钮。
  - 成就 Tab：学习进度条 + 课程考试入口（100% 解锁）+ 电子证书领取。
- [x] 报名/兑换流程：
  - 免费课程：点击「免费报名」直接报名。
  - 学力值课程：点击后弹出确认弹窗，确认后扣减学力值（原型占位，不连接真实服务）。
  - 权益课程：需先领取对应权益，未解锁时显示锁定与查看权益入口。
  - 报名/兑换成功后再次进入详情页，默认展示目录 Tab。
- [x] 学习-考试-证书闭环：
  - 学习页保留「完成本节」与「完成课程并考试」。
  - 课程考试页提交后写入成绩。
  - 进度 100% 且考试通过自动生成可领取的电子证书。
  - 证书领取后可在可信成果 / 长期资产中查看。
- [x] 路由注册：`/courses/center`。
- [x] 通过 mobile `typecheck` / `build`。

## 待后续确认 / 未实现

- [ ] 学习排行榜：课程维度 / 全站维度的学习时长/完成数排行（旧原型能力，待产品确认是否保留）。

## 禁止

- 不自行决定学力值是否可消费；兑换逻辑依赖 F04 Decision A，先用占位规则。
- 不为了游戏化而虚构排行榜真实用户数据。
- 不破坏课程进度与学时的事实边界。

## 验收动线

```text
学院 → 课程中心 → 浏览/筛选课程 → 课程详情
  → 简介 Tab → 报名 / 学力值兑换 / 权益解锁
  → 目录 Tab → 开始学习 / 继续学习 → 课程学习页
  → 成就 Tab → 进度 100% → 课程考试 → 通过 → 领取电子证书
  → 可信成果 / 长期资产查看证书
```

- T008｜可信空间（证书领取入口）
